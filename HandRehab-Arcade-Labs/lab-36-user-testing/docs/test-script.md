# บทดำเนินการทดสอบกับผู้ใช้จริง (Test Script) — HandRehab Arcade

> ใช้คู่กับ `tools/test-recorder.html` (บันทึกดิจิทัล + จับเวลา) หรือพิมพ์หน้านี้ไปจดด้วยมือ
> ผู้เข้าร่วม 5 คน · คนละประมาณ 20–30 นาที · ต้องเซ็นหนังสือยินยอม **ก่อน** เริ่มทุกครั้ง

## ก่อนเริ่ม (5 นาที)

1. เปิดแอปค้างไว้ที่หน้าแรก ล้างข้อมูลผู้ทดสอบคนก่อนออก (หรือใช้รหัสผู้เข้าร่วมใหม่)
2. ตรวจแสง: เปิดไฟห้อง / โคมตั้งโต๊ะ ให้หน้าและมือสว่าง
3. อ่านหนังสือยินยอม (`docs/consent-form.html`) ให้ฟังทีละข้อ แล้วให้ลงชื่อ
4. กำหนดรหัสผู้เข้าร่วม P01–P05 **ห้ามจดชื่อจริงลงในแบบบันทึก**

### คำพูดเปิด (อ่านตามนี้ทุกคน เพื่อให้ทุกคนได้ข้อมูลเท่ากัน)

> "วันนี้เราอยากรู้ว่าแอปของเราใช้ง่ายจริงไหมค่ะ/ครับ เราไม่ได้ทดสอบคุณยาย/คุณตา
> ถ้าทำไม่ได้ แปลว่าแอปของเราต้องแก้ ระหว่างนี้หนูจะนั่งดูเงียบ ๆ และจดบันทึก จะไม่ช่วยบอกนะคะ/ครับ
> ถ้าอยากหยุดหรือรู้สึกเหนื่อย บอกได้ทันทีเลย และช่วยพูดออกมาดัง ๆ ว่ากำลังคิดอะไรอยู่ก็ได้"

## กติกาของผู้สังเกต

- **ห้ามช่วย ห้ามชี้ ห้ามอธิบาย** ระหว่างทำงาน — สิ่งที่ทำไม่ได้คือข้อมูลมีค่าที่สุด
- ถ้าผู้เข้าร่วมติดเกิน **เวลาสูงสุด** ของงานนั้น หรือขอความช่วยเหลือ 2 ครั้ง → ช่วยได้ แล้วบันทึกว่า "ต้องช่วย"
- ถ้ายอมแพ้ / เกินเวลาสูงสุด 2 เท่า → บันทึก "ทำไม่ได้" แล้วไปงานถัดไป
- **จดคำพูดตรง ๆ** ในเครื่องหมายคำพูด เช่น "ปุ่มนี้กดแล้วไม่เห็นเกิดอะไร"
- ห้ามถามว่า "ใช้ง่ายไหม" — ดูว่า **ทำได้จริงหรือไม่** แทน
- จับเวลาจาก "เริ่มได้" จนผู้เข้าร่วมทำเสร็จหรือหยุด
