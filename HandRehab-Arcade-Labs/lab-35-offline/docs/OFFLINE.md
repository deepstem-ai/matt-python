# ใช้งาน HandRehab Arcade แบบไม่มีอินเทอร์เน็ต

วันนำเสนอ อินเทอร์เน็ตมักล่ม หรือเครือข่ายของสถานที่บล็อกเว็บ แลปนี้ทำให้ **ทุกฟีเจอร์ทำงานได้โดยไม่ต้องใช้เน็ตเลย**
รวมถึงการจับมือและใบหน้าด้วย AI

## แอปหาไฟล์อย่างไร
ทุกที่อยู่ของไฟล์ภายนอกอยู่ใน `js/assets.js` ที่เดียว ฟังก์ชัน `assetUrl(ชื่อไฟล์)` หา **ในเครื่องก่อน แล้วค่อยอินเทอร์เน็ต**

| กลุ่ม | ไฟล์ในเครื่อง | ถ้าไม่มี ใช้ |
|---|---|---|
| โมเดล AI 3 ไฟล์ | `models/hand_landmarker.task`, `models/face_landmarker.task`, `models/blaze_face_short_range.tflite` | storage.googleapis.com (`/1/` แล้ว `/latest/`) |
| ไลบรารี MediaPipe 0.10.14 | `vendor/tasks-vision/vision_bundle.mjs` + `vendor/tasks-vision/wasm/` (4 ไฟล์) | cdn.jsdelivr.net แล้ว unpkg.com |
| ฟอนต์ | `fonts/noto-sans-thai-thai.woff2`, `fonts/noto-sans-thai-latin.woff2`, `fonts/orbitron-latin.woff2` + `fonts/fonts.css` | Google Fonts (ถ้าออฟไลน์ด้วย ใช้ฟอนต์ของระบบ) |

รวม **12 ไฟล์** ไฟล์เหล่านี้ใหญ่ (~31 MB) จึง **ไม่อยู่ใน git** (ดู `.gitignore`) ทุกเครื่องต้องรันสคริปต์ดาวน์โหลดเองหนึ่งครั้ง

---

## 1) เตรียมเครื่อง (ต้องต่ออินเทอร์เน็ต ครั้งเดียว)
**Windows**
1. เปิดโฟลเดอร์แอป → โฟลเดอร์ `tools` → ดับเบิลคลิก **`download-assets.bat`**
   (หรือเปิด PowerShell ในโฟลเดอร์แอป แล้วพิมพ์ `powershell -ExecutionPolicy Bypass -File tools\download-assets.ps1`)
2. รอจนขึ้น **"สรุป: สำเร็จ 12 / 12 ไฟล์"** (ประมาณ 1–3 นาที)
3. ถ้าบางไฟล์ไม่สำเร็จ สคริปต์จะลองลิงก์สำรองให้เองแล้ว ถ้ายังไม่ได้: ใช้เน็ตมือถือ (Hotspot) แล้วรันใหม่ ไฟล์ที่ได้แล้วจะไม่โหลดซ้ำ

**Mac / Linux**
```bash
bash tools/download-assets.sh
```

## 2) ตรวจว่าใช้ได้จริง (ห้ามแค่ "คิดว่าได้")
1. ดับเบิลคลิก `start.bat` (ใช้ `tools/serve.py` ซึ่งบังคับชนิดไฟล์ .js/.mjs/.wasm ให้ถูกทุกเครื่อง)
2. ดู **ป้ายมุมซ้ายล่าง** ต้องขึ้น **"✔ ไฟล์ในเครื่องครบ 12/12"** (กรอบสีเขียว)
3. กดที่ป้าย → **🔍 ตรวจทุกไฟล์ (โหลดจริง)** ทุกแถวต้องเป็น ✔ พร้อมขนาดไฟล์
4. **ปิด Wi-Fi และถอดสาย LAN จริง ๆ** แล้วปิดเบราว์เซอร์ทั้งหมด
5. เปิด `start.bat` ใหม่ ป้ายต้องขึ้น **"📴 ออฟไลน์ · ใช้ไฟล์ในเครื่อง"**
6. ทำครบทุกอย่าง: หน้าเปิดแอปโหลดถึง 100% → เข้าสู่ระบบด้วยใบหน้า → เล่นเกมทั้ง 3 เกมด้วยมือจริง → ดูความก้าวหน้า → หน้าตั้งค่า
7. กด **F12 → Console** ต้องเห็น `[vision] ไลบรารีจาก http://localhost:8000/vendor/...` และ `โหลดโมเดลสำเร็จ http://localhost:8000/models/...` (ไม่ใช่ googleapis)
8. จดผลลงสมุดบันทึก พร้อมวันเวลา และถ่ายภาพหน้าจอเก็บไว้เป็นหลักฐาน

## 3) ชุด USB (เปิดได้ทุกเครื่อง)
```
Windows:  powershell -ExecutionPolicy Bypass -File tools\make-usb-package.ps1
Mac:      bash tools/make-usb-package.sh
```
ได้โฟลเดอร์ `dist/HandRehab-USB/` → คัดลอกทั้งโฟลเดอร์ลง USB อ่าน `README-USB.txt` ในนั้น
เครื่องที่ไม่มี Python: ใส่ **Python embeddable (Windows 64-bit)** ลงโฟลเดอร์ `python\` บน USB (ดู `python\README.txt`) `start.bat` บน USB จะใช้ตัวนั้นก่อน

## ⏰ กำหนดเวลา
- **อย่างน้อย 7 วันก่อนนำเสนอ:** ทำแลปนี้ให้เสร็จ และผ่านการทดสอบข้อ 2 ครบ (มีเวลาแก้ถ้ามีปัญหา)
- **3 วันก่อนนำเสนอ:** ทำเช็กลิสต์ด้านล่างให้ครบทุกข้อ
- **เช้าวันนำเสนอ:** ทดสอบซ้ำข้อ 2 อีกรอบบนเครื่องที่จะใช้จริง

## ✅ เช็กลิสต์ 3 วันก่อนนำเสนอ
- [ ] รัน `download-assets` บนเครื่องที่จะใช้นำเสนอ ได้ **12/12**
- [ ] ป้ายมุมจอขึ้น **ไฟล์ในเครื่องครบ 12/12** และ "ตรวจทุกไฟล์ (โหลดจริง)" ผ่านทุกแถว
- [ ] ปิด Wi-Fi + ถอดสาย LAN แล้ว: หน้าเปิดแอปถึง 100% โดยไม่มีช่องสีแดง
- [ ] ออฟไลน์: เข้าสู่ระบบด้วยใบหน้าได้ และเข้าด้วย PIN ได้
- [ ] ออฟไลน์: เล่นครบ 3 เกมด้วยมือจริง คะแนนถูกบันทึก เห็นในหน้าความก้าวหน้า
- [ ] ออฟไลน์: ฟอนต์ไทยแสดงถูก (ไม่เป็นฟอนต์ Tahoma) และตัวเลขเป็นฟอนต์ Orbitron
- [ ] สร้างชุด USB 2 อัน และทดสอบเปิดจาก USB บน **อีกเครื่องหนึ่ง** ที่ปิดเน็ต
- [ ] เครื่องสำรองไม่มี Python → ใส่ Python พกพาในโฟลเดอร์ `python\` แล้วทดสอบแล้ว
- [ ] ส่งออกข้อมูลผู้ใช้ทดสอบ (หน้า "ผู้ใช้" → ส่งออก) เก็บไว้ในที่ปลอดภัย (ห้ามอัปโหลดขึ้นเน็ต)
- [ ] ทดสอบกล้องตัวที่จะใช้จริง (เลือกในหน้าตั้งค่า) และแสงในห้องนำเสนอ
- [ ] รันหน้า "ทดสอบความลื่นของเครื่อง" บนเครื่องนำเสนอ แล้วกด "ใช้ค่าแนะนำ"
- [ ] ติดตั้งเป็นแอป (docs/INSTALL.md) และเปิดจากไอคอนได้ ไม่มีแถบเบราว์เซอร์
- [ ] ชาร์จแบตโน้ตบุ๊ก เตรียมสายไฟ สาย USB กล้อง และปลั๊กพ่วง

## ปัญหาที่พบบ่อย
| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ป้ายขึ้น "ขาด N ไฟล์" | ยังไม่ได้รัน download-assets หรือรันไม่ครบ → รันใหม่ |
| สคริปต์ .ps1 เปิดไม่ได้ "running scripts is disabled" | ใช้ `download-assets.bat` หรือพิมพ์คำสั่งที่มี `-ExecutionPolicy Bypass` |

| จอว่าง Console บอก MIME type "text/plain" | เปิดด้วย `python -m http.server` บน Windows ที่ตั้งค่ารีจิสทรีเพี้ยน → ใช้ `start.bat` (tools/serve.py) |
