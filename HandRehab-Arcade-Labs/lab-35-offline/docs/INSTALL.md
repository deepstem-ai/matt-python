# วิธีติดตั้ง HandRehab Arcade เป็นแอปในเครื่อง

ติดตั้งแล้วจะมี **ไอคอนมือเรืองแสง** บนเดสก์ท็อป / หน้าจอโฮม กดเปิดแล้วเป็นหน้าต่างแอปของตัวเอง **ไม่มีแถบที่อยู่เว็บ** และเปิดได้แม้ไม่มีอินเทอร์เน็ต (หลังจากเปิดออนไลน์ครบ 1 รอบแล้ว)

> ⚠ ต้องเปิดแอปผ่าน `http://localhost:8000` เสมอ (ดับเบิลคลิก `start.bat` บน Windows หรือ `bash start.sh` บน Mac)
> ถ้าเปิดไฟล์ `index.html` ตรง ๆ (ที่อยู่ขึ้นต้นด้วย `file:///`) จะ **ติดตั้งไม่ได้** และปุ่มติดตั้งจะไม่ขึ้น

---

## ก่อนติดตั้ง (ทำครั้งเดียว ต้องมีอินเทอร์เน็ต)
1. ดับเบิลคลิก `start.bat` (Windows) หรือพิมพ์ `bash start.sh` ใน Terminal (Mac)
2. เบราว์เซอร์จะเปิด `http://localhost:8000` เอง รอหน้าเปิดแอป (splash) โหลดจนถึง **100%**
   ขั้นนี้ดาวน์โหลดโมเดล AI มือและใบหน้า (ประมาณ 12 MB) เก็บไว้ในเครื่อง
3. เข้าสู่ระบบ แล้วลองเข้าเกมใดเกมหนึ่ง 1 ครั้ง (ให้แอปเก็บไฟล์ของเกมครบ)

---

## Windows — Google Chrome
1. เปิด `http://localhost:8000` ใน **Chrome**
2. กดปุ่ม **⚙ ตั้งค่า** ที่แถบล่างของแอป → หัวข้อ **📲 ติดตั้งเป็นแอป** → กดปุ่มสีเขียว **⬇ ติดตั้งแอปลงเครื่อง**
   - ถ้าไม่เห็นปุ่มสีเขียว: ดูที่ **ช่องที่อยู่เว็บด้านขวาสุด** จะมีไอคอน **จอคอมพิวเตอร์มีลูกศรชี้ลง** (⊕ ติดตั้ง) กดที่ไอคอนนั้น
   - หรือกดเมนู **⋮ (จุดสามจุด มุมขวาบน)** → **แคสต์ บันทึก และแชร์** → **ติดตั้ง HandRehab…** (Chrome รุ่นเก่า: **ติดตั้ง HandRehab Arcade…**)
3. หน้าต่างถามยืนยันขึ้น → กด **ติดตั้ง**
4. แอปจะเปิดเป็นหน้าต่างใหม่ทันที และมีไอคอน **HandRehab** บนเดสก์ท็อปกับในเมนู Start
5. ถ้าไม่มีไอคอนบนเดสก์ท็อป: พิมพ์ `chrome://apps` ในช่องที่อยู่ → คลิกขวาที่ **HandRehab** → **สร้างทางลัด…** → ติ๊ก **เดสก์ท็อป** → **สร้าง**

## Windows — Microsoft Edge
1. เปิด `http://localhost:8000` ใน **Edge**
2. กด **⚙ ตั้งค่า** ในแอป → **⬇ ติดตั้งแอปลงเครื่อง**
   - หรือกดไอคอน **สี่เหลี่ยมมีเครื่องหมาย +** (แอปพร้อมใช้งาน) ท้ายช่องที่อยู่เว็บ
   - หรือเมนู **… (จุดสามจุด มุมขวาบน)** → **แอป** → **ติดตั้งไซต์นี้เป็นแอป**
3. กด **ติดตั้ง** → Edge ถามว่าจะปักหมุดที่ไหน ติ๊ก **สร้างทางลัดบนเดสก์ท็อป** และ **ปักหมุดที่แถบงาน** → กด **อนุญาต**

## Mac — Chrome
1. เปิด `http://localhost:8000` ใน **Chrome**
2. กด **⚙ ตั้งค่า** ในแอป → **⬇ ติดตั้งแอปลงเครื่อง** (หรือไอคอนติดตั้งท้ายช่องที่อยู่ / เมนู **⋮** → **แคสต์ บันทึก และแชร์** → **ติดตั้ง…**)
3. กด **ติดตั้ง** → แอปอยู่ในโฟลเดอร์ **Applications → Chrome Apps** และเปิดจาก **Launchpad** ได้
4. ลากไอคอนจาก Launchpad ไปวางที่ **Dock** เพื่อเปิดง่าย

## Mac — Edge
เหมือน Windows — Edge: เมนู **…** → **แอป** → **ติดตั้งไซต์นี้เป็นแอป** → **ติดตั้ง**

## Mac / iPad — Safari (เพิ่มไปยังหน้าจอโฮม)
> Safari ไม่มีปุ่มติดตั้งอัตโนมัติ ปุ่มสีเขียวในแอปจึงไม่ขึ้น ใช้ขั้นตอนนี้แทน
>
> **iPad ต้องเปิดจากคอมพิวเตอร์ที่รันแอปผ่านเครือข่ายเดียวกัน** เช่น `http://192.168.1.20:8000`
> แต่ iPad จะใช้กล้องและติดตั้งได้เฉพาะเว็บที่เป็น `https://` หรือ `localhost` เท่านั้น — ทางที่ง่ายที่สุดคือให้ครูนำแอปขึ้นเว็บ https (เช่น GitHub Pages) แล้วเปิดลิงก์นั้นบน iPad

**iPad (Safari)**
1. เปิดลิงก์ของแอปใน **Safari**
2. แตะปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรชี้ขึ้น ⬆ มุมขวาบน)
3. เลื่อนลงแล้วแตะ **เพิ่มไปยังหน้าจอโฮม** (Add to Home Screen)
4. ชื่อจะขึ้นว่า **HandRehab** → แตะ **เพิ่ม** มุมขวาบน
5. ไอคอนมือเรืองแสงจะอยู่บนหน้าจอโฮม แตะเปิดแล้วเต็มจอไม่มีแถบ Safari

**Mac (Safari 17 ขึ้นไป)**: เมนู **ไฟล์** → **เพิ่มไปยัง Dock…** → **เพิ่ม**

## ตรวจว่าติดตั้งสำเร็จ
- [ ] มีไอคอน **HandRehab** บนเดสก์ท็อป / Dock / หน้าจอโฮม
- [ ] เปิดจากไอคอนแล้ว **ไม่มีแถบที่อยู่เว็บ** ด้านบน
- [ ] ในหน้า **⚙ ตั้งค่า** ขึ้นว่า **"✔ ติดตั้งแล้ว"** และปุ่มติดตั้งหายไป
- [ ] ปิด Wi-Fi แล้วเปิดแอปจากไอคอน ยังเข้าได้ (ต้องเปิด `start.bat` ไว้ด้วย — แอปคุยกับเซิร์ฟเวอร์เล็ก ๆ ในเครื่อง)

## อัปเดตเป็นเวอร์ชันใหม่
1. ทีมแก้โค้ดแล้ว **เปลี่ยนเลข `VERSION` ในไฟล์ `sw.js`** (เช่น `v1.0.0` → `v1.0.1`)
2. เปิดแอปที่ติดตั้งไว้ รอสักครู่ จะมีแถบ **"🆕 มีแอปเวอร์ชันใหม่แล้ว"** → กด **↻ โหลดเวอร์ชันใหม่**
3. แอปโหลดใหม่เอง แคชเก่าถูกลบทิ้งอัตโนมัติ

## ปุ่มติดตั้งไม่ขึ้น ทำอย่างไร
1. ตรวจว่าที่อยู่เว็บเป็น `http://localhost:8000` ไม่ใช่ `file:///`
2. กด **F12** → แท็บ **Application** → **Manifest** : จะบอกชัดเจนว่าขาดอะไร (เช่น ไอคอนหาย)
3. ในแท็บเดียวกัน → **Service workers** : ต้องขึ้นว่า **activated and is running**
4. ถ้าเคยติดตั้งแล้ว ปุ่มจะไม่ขึ้นอีก (ถูกต้องแล้ว) ให้เปิดจากไอคอน
5. ถอนการติดตั้ง: เปิดแอป → เมนู **⋮** มุมขวาบนของหน้าต่างแอป → **ถอนการติดตั้ง HandRehab**

## ปุ่มเต็มจอ (สำหรับวันนำเสนอ)
กดปุ่ม **⛶ เต็มจอ** ที่แถบบนของทุกหน้า (หรือกด **F11**) กดซ้ำหรือกด **Esc** เพื่อออก
