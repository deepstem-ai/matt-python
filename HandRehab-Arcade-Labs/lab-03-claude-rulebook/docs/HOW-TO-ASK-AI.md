# วิธีสั่ง AI ให้ได้โค้ดที่ใช้ได้จริง (คู่มือสำหรับทีม)

> AI เก่งแค่ไหน ก็ทำได้ดีเท่าที่เราสั่งชัดเท่านั้น
> Claude Code **อ่านและแก้ไฟล์ในเครื่องเราได้จริง** — ถ้าสั่งกว้าง ๆ มันจะไปแก้ไฟล์ที่เราไม่อยากให้แตะ

## คำสั่งที่ดีมี 5 ส่วน — สูตร 5 บรรทัด
ก๊อปไปใช้ได้ทุกแลป เติมหลังเครื่องหมาย `:` ให้ครบ

```
ตอนนี้มี          : ไฟล์อะไรทำงานได้แล้วบ้าง
อยากได้           : สิ่งที่ต้องการ พูดให้ชัดเป็นรูปธรรม
ห้ามทำ            : ไฟล์ที่ห้ามแตะ ไลบรารีที่ห้ามเพิ่ม
เสร็จแล้วต้องเห็น : ฉันจะกดอะไร แล้วต้องเห็นอะไรบนจอ
รูปแบบ            : บอกแผนก่อน รอฉันพิมพ์ GO แล้วค่อยเขียน
```

(ในเอกสารคอร์สใช้คำว่า OK — ทีมเราตกลงใช้คำว่า **GO** ให้ตรงกับ CLAUDE.md)

### ตัวอย่างสูตร 5 บรรทัด จากโปรเจกต์เราเอง
```
ตอนนี้มี          : index.html เปิดกล้องได้ มีป้าย FPS มุมขวาบน
อยากได้           : ปุ่ม "ถ่ายรูป" ขนาดสูง 56px ข้างปุ่มปิดกล้อง กดแล้วบันทึกภาพนิ่งเป็นไฟล์ PNG
ห้ามทำ            : ห้ามแก้ส่วนจัดการ error และส่วนนับ FPS ห้ามเพิ่มไลบรารี
เสร็จแล้วต้องเห็น : กดปุ่มแล้วมีไฟล์ .png ลงโฟลเดอร์ Downloads และภาพไม่กลับซ้ายขวาผิด
รูปแบบ            : บอกแผนก่อน รอฉันพิมพ์ GO แล้วค่อยเขียน
```

## 3 คู่ตัวอย่าง: คำสั่งอ่อน vs คำสั่งแข็ง (จากโปรเจกต์นี้)

### คู่ที่ 1 — ขอฟีเจอร์ใหม่
| ❌ คำสั่งอ่อน | ✅ คำสั่งแข็ง |
|---|---|
| "ทำเกมมือให้หน่อย" | "สร้างไฟล์ `js/geometry.js` ที่มี 5 ฟังก์ชัน: `dist`, `angle`, `fingerCurl`, `spread`, `palmScale` ตามสเปกที่แนบ เป็นฟังก์ชันล้วน ห้ามแตะกล้องหรือหน้าจอ พร้อมหน้า `geometry-test.html` ที่ฉันเปิดแล้วเห็นผลทดสอบเป็นสีเขียว/แดง" |

**ทำไมแข็งกว่า:** บอกชื่อไฟล์ ชื่อฟังก์ชัน ขอบเขต (ห้ามแตะอะไร) และวิธีตรวจว่าเสร็จจริง

### คู่ที่ 2 — แจ้งบั๊ก
| ❌ คำสั่งอ่อน | ✅ คำสั่งแข็ง |
|---|---|
| "มัน error ช่วยแก้ที" | "ฉันเปิดผ่าน start.bat แล้วกดปุ่ม ▶ เปิดกล้อง จอกลายเป็นสีดำ ป้าย FPS ขึ้น 0 ฉันคาดว่าจะเห็นภาพกล้อง นี่คือข้อความใน Console ทั้งหมด: (วางข้อความสีแดงทั้งหมด) อธิบายสาเหตุก่อน ยังไม่ต้องแก้" |

**ทำไมแข็งกว่า:** บอกขั้นตอนที่ทำ สิ่งที่เห็น สิ่งที่คาดว่าจะเห็น และหลักฐานจาก Console (F12)

### คู่ที่ 3 — ขอแก้ของที่มีอยู่
| ❌ คำสั่งอ่อน | ✅ คำสั่งแข็ง |
|---|---|
| "ทำใหม่หมดเลย ไม่สวย" | "แก้เฉพาะฟังก์ชัน `showError` ใน index.html ให้กล่องแจ้งปัญหามีรูปไอคอนกล้องขีดฆ่าด้านบน ห้ามแตะไฟล์อื่น ห้ามแก้ฟังก์ชันอื่นในไฟล์นี้ และห้ามเปลี่ยนข้อความภาษาไทยที่มีอยู่" |

**ทำไมแข็งกว่า:** จำกัดขอบเขตชัดเจน → AI ไม่ไปทับโค้ดที่ทำงานได้แล้ว

### แถม — เรื่องไลบรารี
| ❌ | ✅ |
|---|---|
| "ลง library เพิ่มได้เลย" | "ห้ามเพิ่มไลบรารีใหม่ ถ้าจำเป็นจริงให้บอกชื่อกับเหตุผลแล้วรอฉันอนุมัติก่อน" |

## เช็กลิสต์ก่อนกด Enter
- [ ] บอกชื่อไฟล์ที่เกี่ยวข้องแล้ว
- [ ] บอกสิ่งที่ **ห้าม** แตะแล้ว
- [ ] บอกว่าเสร็จแล้วต้อง **กดอะไร เห็นอะไร**
- [ ] ถ้าแตะเกิน 2 ไฟล์ → ขอแผนก่อน รอพิมพ์ GO

## หลัง AI ตอบ
1. อ่านทุกบรรทัดที่ AI เขียนก่อนรับ แล้ว **ถามคำถามต่ออย่างน้อย 1 ข้อ** เช่น "บรรทัดนี้ทำอะไร" "ถ้าไม่มีกล้องจะเกิดอะไรขึ้น"
2. ทดสอบตามที่เขียนไว้ใน "เสร็จแล้วต้องเห็น"
3. ห้ามปล่อย AI ทำงานคนเดียวนาน 30 นาที — หยุดตรวจทุกแลป
4. คำสั่งไหนได้ผลดี เก็บไว้ในโฟลเดอร์ `prompts/` ให้เพื่อนใช้ต่อ

## ให้ AI ช่วยเขียนคำสั่งให้
ถ้าคิดไม่ออกว่าจะสั่งอย่างไร ก๊อปข้อความนี้ไปวางก่อน:
```
คุณคือผู้เชี่ยวชาญการเขียนคำสั่งให้ AI เขียนโค้ด
ฉันจะบอกงานแบบหยาบ ๆ ให้คุณแปลงเป็นคำสั่งที่ดีที่มีครบ 5 ส่วน
1) ตอนนี้มีอะไร  2) อยากได้อะไร  3) ห้ามทำอะไร
4) เสร็จแล้วต้องเห็นอะไร  5) รูปแบบการตอบ
ห้ามเขียนโค้ดในขั้นนี้ ให้ออกมาเป็นคำสั่งที่ฉันเอาไปวางต่อเท่านั้น
และเตือนฉัน 3 ข้อว่าคำสั่งนี้ยังไม่ชัดตรงไหน

งานที่อยากทำคือ : ___
```
