# แม่แบบแจ้งบั๊ก (ใช้ได้ทุกแลป)
```
ตอนนี้มี          : (ไฟล์ที่เกี่ยวข้อง) ทำงานได้ถึงขั้น ___
อยากได้           : หาสาเหตุที่ ___ (ขั้นตอนที่ฉันทำ: 1) ___ 2) ___)
                    ฉันเห็น ___ แต่คาดว่าจะเห็น ___
                    ข้อความใน Console (F12) ทั้งหมด: ___
ห้ามทำ            : ห้ามแก้ไฟล์อื่นนอกจาก ___ ห้ามเขียนทับฟังก์ชันที่ทำงานได้แล้ว
เสร็จแล้วต้องเห็น : ทำขั้นตอนเดิมซ้ำแล้วเห็น ___ และ Console ไม่มีบรรทัดสีแดง
รูปแบบ            : อธิบายสาเหตุเป็นภาษาไทยง่าย ๆ ก่อน เสนอวิธีแก้ รอฉันพิมพ์ GO
```
