# Lab 01 — เปิดกล้องด้วยไฟล์เดียว (ใช้แล้วได้ผล)
```
ตอนนี้มี          : โฟลเดอร์ว่าง handrehab-arcade มีไฟล์ index.html ว่าง ๆ
อยากได้           : index.html ไฟล์เดียว พื้น #0B1020 ตัวอักษร #F8FAFC หัวเรื่อง "HandRehab Arcade"
                    ปุ่ม "▶ เปิดกล้อง" สูง ≥ 56px เรียก getUserMedia 1280x720 ภาพกระจก ไม่บิดสัดส่วน
                    ป้าย FPS มุมขวาบนอัปเดตทุกวินาที
ห้ามทำ            : ห้ามใช้ไลบรารี ห้าม npm คอมเมนต์ต้องเป็นภาษาไทย
เสร็จแล้วต้องเห็น : กดปุ่มแล้วเห็นหน้าตัวเอง ถ้ากด "ไม่อนุญาต" / ไม่มีกล้อง / กล้องถูกใช้อยู่
                    ต้องเห็นข้อความไทย + ปุ่มลองใหม่ ห้ามจอว่าง
รูปแบบ            : อธิบาย getUserMedia ก่อน แล้วบอกแผน รอฉันพิมพ์ GO แล้วค่อยเขียน
```
**ผลที่ได้:** (ทีมจดเอง เช่น ทำงานรอบแรกไหม FPS เท่าไร ข้อผิดพลาดทั้ง 3 แบบขึ้นข้อความไทยครบไหม)
