# วิธีเปิดแอป HandRehab Arcade (ฉบับคนไม่เคยใช้คอมพิวเตอร์)

> อ่านทีละข้อ ทำตามทีละข้อ ไม่ต้องรีบ ถ้าติดตรงไหน ดูหัวข้อ "ถ้ามีปัญหา" ด้านล่าง

## ก่อนเริ่ม ต้องมี 3 อย่าง (ทำครั้งเดียว)
1. **คอมพิวเตอร์ที่มีกล้อง** — โน้ตบุ๊กส่วนใหญ่มีกล้องเล็ก ๆ อยู่เหนือจอ ถ้าเป็นคอมตั้งโต๊ะ ให้เสียบกล้อง USB
2. **โปรแกรม Google Chrome** — ไอคอนวงกลมสีแดง เหลือง เขียว ฟ้า (ถ้าไม่มี ใช้ Microsoft Edge แทนได้)
3. **โปรแกรม Python** — เป็นตัวช่วยเปิด "เซิร์ฟเวอร์เล็ก ๆ" ในเครื่องเรา ไม่ต้องใช้อินเทอร์เน็ต
   - กดปุ่มรูปหน้าต่าง ⊞ ที่มุมซ้ายล่างของแป้นพิมพ์
   - พิมพ์คำว่า `Microsoft Store` แล้วกด Enter
   - ในช่องค้นหาด้านบน พิมพ์ `python` แล้วกด Enter
   - คลิก **Python 3** ตัวที่ตัวเลขมากที่สุด แล้วกดปุ่ม **รับ (Get)**
   - รอจนขึ้นว่าติดตั้งเสร็จ ปิด Store ได้เลย

## เปิดแอป (ทำทุกครั้งที่อยากใช้)
1. เปิดโฟลเดอร์ของแอป (โฟลเดอร์ที่มีไฟล์ `index.html` และ `start.bat`)
2. **ดับเบิลคลิก** ไฟล์ชื่อ `start.bat` (คลิกซ้าย 2 ครั้งเร็ว ๆ)
   - ถ้า Windows ขึ้นกล่องสีฟ้า "Windows protected your PC" ให้กด **More info** แล้วกด **Run anyway**
3. จะมีหน้าต่างสีดำขึ้นมา พร้อมโลโก้ทีม — **อย่าปิดหน้าต่างนี้** ระหว่างใช้งาน
4. รอ 2–5 วินาที หน้าต่างแอปจะเปิดขึ้นมาเอง (ไม่มีแถบพิมพ์ที่อยู่ ดูเหมือนแอปจริง)
5. กดปุ่มใหญ่ **▶ เปิดกล้อง** แล้วกด **อนุญาต (Allow)** เมื่อ Chrome ถาม
6. เห็นหน้าตัวเองบนจอ = สำเร็จ 🎉

**อยากเปิดเต็มจอสำหรับสาธิตหน้าชั้น?** ดับเบิลคลิก `start-kiosk.bat` แทน (ออกจากเต็มจอด้วย `Alt + F4`)

## ปิดแอป (เมื่อใช้เสร็จ)
1. ปิดหน้าต่างแอป — กดกากบาท ✕ มุมขวาบน หรือกด `Alt + F4`
2. ที่แถบด้านล่างของจอ จะมีหน้าต่างชื่อ **HandRehab Server** ย่ออยู่ — คลิกเปิดแล้วกด ✕ ปิด
3. กลับไปที่หน้าต่างสีดำอันแรก กดปุ่มอะไรก็ได้ 1 ครั้ง มันจะปิดเอง

## ใช้ Mac หรือ Linux
1. เปิดโปรแกรม **Terminal**
2. พิมพ์ `cd ` (มีเว้นวรรค) แล้วลากโฟลเดอร์ของแอปมาวางในหน้าต่าง กด Enter
3. พิมพ์ `bash start.sh` แล้วกด Enter (แบบเต็มจอ: `bash start.sh kiosk`)
4. ใช้เสร็จแล้ว กลับมาที่ Terminal กด Enter หนึ่งครั้ง เซิร์ฟเวอร์จะปิดเอง

## วิธีสำรอง (ถ้า start.bat ใช้ไม่ได้)
1. เปิดโฟลเดอร์ของแอป คลิกที่ช่องที่อยู่ด้านบนของหน้าต่างโฟลเดอร์ พิมพ์ `cmd` แล้วกด Enter
2. ในหน้าต่างสีดำ พิมพ์ `python -m http.server 8000` แล้วกด Enter
3. เปิด Chrome พิมพ์ `http://localhost:8000` ที่ช่องที่อยู่ แล้วกด Enter

## ถ้ามีปัญหา
| เห็นอะไร | แปลว่า | ทำอย่างไร |
|---|---|---|
| หน้าต่างดำขึ้นตัวแดง "ยังไม่มีโปรแกรม Python" | ยังไม่ได้ติดตั้ง Python | ทำตามหัวข้อ "ก่อนเริ่ม" ข้อ 3 แล้วเปิด `start.bat` ใหม่ |
| "พอร์ต 8000-8004 ถูกใช้หมด" | เปิด start.bat ค้างไว้หลายรอบ | ปิดหน้าต่าง "HandRehab Server" ทุกอัน หรือรีสตาร์ตเครื่อง |
| แอปไม่ขึ้นภายใน 5 วินาที | เครื่องช้า หรือไม่พบ Chrome | เปิด Chrome เอง แล้วพิมพ์ที่อยู่ที่หน้าต่างดำบอก เช่น `http://localhost:8000` |
| แถบเหลือง "ตอนนี้เปิดไฟล์ตรง ๆ อยู่" | ดับเบิลคลิก `index.html` แทน `start.bat` | ปิดหน้านั้น แล้วดับเบิลคลิก `start.bat` |
| กล่องแดง "ยังไม่ได้อนุญาตให้ใช้กล้อง" | กด "ไม่อนุญาต" ไปแล้ว | กดรูปกล้อง/แม่กุญแจด้านบน เลือก "อนุญาต" แล้วกด "ลองใหม่อีกครั้ง" |
| กล่องแดง "กล้องกำลังถูกโปรแกรมอื่นใช้อยู่" | Zoom / LINE / Teams เปิดกล้องอยู่ | ปิดโปรแกรมพวกนั้น แล้วกด "ลองใหม่อีกครั้ง" |
| ข้อความ "failed to load module" | เปิดไฟล์ตรง ๆ ไม่ผ่าน localhost | เปิดผ่าน `start.bat` เสมอ |
