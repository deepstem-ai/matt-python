## 3.3 สมการและขั้นตอนวิธีที่ใช้

กำหนดให้ Pᵢ = (xᵢ, yᵢ, zᵢ) คือจุดที่ i ของมือ (i = 0–20) ในพิกัดปรับค่า 0–1 จาก MediaPipe และ d(A, B) = √((xₐ−x_b)² + (yₐ−y_b)² + (zₐ−z_b)²)

**(3.1) ขนาดฝ่ามือ** S = d(P0, P9)

**(3.2) ระยะปรับมาตรฐาน** normDist(i, j) = d(Pᵢ, Pⱼ) / S  — ไม่ขึ้นกับระยะห่างจากกล้อง

**(3.3) มุมที่ข้อต่อ** angle(A, B, C) = arccos( (u · v) / (|u| |v|) ) × 180/π เมื่อ u = A − B และ v = C − B

**(3.4) ความงอของนิ้ว** สำหรับนิ้ว (m, p, d, t) = (โคน, ข้อกลาง, ข้อปลาย, ปลายนิ้ว)
θ₁ = angle(P0, Pm, Pp), θ₂ = angle(Pm, Pp, Pd), θ₃ = angle(Pp, Pd, Pt)
θ̄ = (0.5θ₁ + θ₂ + θ₃) / 2.5 และ curl = clamp((180 − θ̄) / 110, 0, 1)
สำหรับนิ้วโป้ง curl = clamp((180 − (θ₂ + θ₃)/2) / 70, 0, 1)

**(3.5) มุมกางนิ้ว** spread(a, b) = angle ระหว่างเวกเตอร์ (P_tip,a − P_mcp,a) และ (P_tip,b − P_mcp,b) เช่น นิ้วชี้ (P5→P8) กับนิ้วก้อย (P17→P20)

**(3.6) คะแนนท่า 0–1** scoreLow(v; full, zero) = clamp((zero − v)/(zero − full), 0, 1) และ scoreHigh(v; zero, full) = clamp((v − zero)/(full − zero), 0, 1)
- จีบนิ้ว: score = scoreLow(normDist(4, 8); 0.25, 0.8)
- กำมือ: score = scoreHigh(ค่าเฉลี่ย curl นิ้วชี้–ก้อย; 0.3, 0.8)
- แบมือกางนิ้ว: score = scoreHigh(spread(ชี้, ก้อย); 15°, 45°) × clamp(1 − 1.5 × curl เฉลี่ย, 0, 1)
- งอ-เหยียดข้อมือ: score = scoreHigh(มุมระหว่าง (P9 − P0) กับแกนแนวตั้ง; 10°, 45°)
(ค่าคงที่ข้างต้นคือค่าเริ่มต้นใน js/gestures.js ซึ่งถูกแทนด้วยค่ารายบุคคลหลังการปรับเทียบ)

**(3.7) เกณฑ์รายบุคคลจากการปรับเทียบ** T_enter = r − kₑ(r − b), T_exit = r − kₓ(r − b) เมื่อ r = ค่าขณะพัก b = ค่าดีที่สุดของผู้ใช้ kₑ, kₓ = [[ใส่ค่าจาก Lab 27: ค่า k เข้า/ออก ที่ใช้จริง #calib_k]]

**(3.8) ระดับอาการมือสั่น** σ = ส่วนเบี่ยงเบนมาตรฐานของตำแหน่ง P8 (หารด้วย S) ขณะวางมือนิ่ง [[ใส่ค่าจาก Lab 27: ระยะเวลาวัดขณะนิ่ง (วินาที) #tremor_sec]] วินาที แบ่ง 4 ระดับตามเกณฑ์ [[ใส่ค่าจาก Lab 27: ค่าแบ่งระดับอาการสั่น #tremor_cuts]]

**(3.9) ตัวนับครั้งแบบประตูสองบาน (hysteresis)** สถานะ idle → (score ≥ enter) → engaging → (ค้าง ≥ minHold) → held → (score ≤ exit) → นับ 1 ครั้ง → cooldown (cooldownMs) → idle
ค่าที่ใช้ enter = [[ใส่ค่าจาก Lab 21: enter #rep_enter]], exit = [[ใส่ค่าจาก Lab 21: exit #rep_exit]], minHold = [[ใส่ค่าจาก Lab 21: minHoldMs #rep_hold]] ms, cooldown = [[ใส่ค่าจาก Lab 21: cooldownMs #rep_cooldown]] ms โดย exit < enter เพื่อกันการนับซ้ำจากสัญญาณสั่น

**(3.10) ตัวกรอง One Euro (Casiez และคณะ, 2012)** ที่เวลา tᵢ, Tₑ = tᵢ − tᵢ₋₁
α(f_c) = 1 / (1 + τ/Tₑ), τ = 1/(2π f_c)
ẋᵢ = (xᵢ − x̂ᵢ₋₁)/Tₑ, ẋ̂ᵢ = α(d_cutoff) ẋᵢ + (1 − α(d_cutoff)) ẋ̂ᵢ₋₁
f_c = f_cmin + β |ẋ̂ᵢ|, x̂ᵢ = α(f_c) xᵢ + (1 − α(f_c)) x̂ᵢ₋₁
พารามิเตอร์ f_cmin = [[ใส่ค่าจาก Lab 27: minCutoff #oe_mincutoff]], β = [[ใส่ค่าจาก Lab 27: beta #oe_beta]], d_cutoff = [[ใส่ค่าจาก Lab 27: dCutoff #oe_dcutoff]]
การลดการสั่น (%) = (1 − σ_กรองแล้ว / σ_ดิบ) × 100

**(3.11) ความคล้ายของใบหน้า (cosine similarity)** sim(a, b) = (a · b) / (|a| |b|) เมื่อ a, b คือเวกเตอร์ลักษณะใบหน้า ยอมรับเมื่อ sim ≥ [[ใส่ค่าจาก Lab 15: เกณฑ์ความคล้าย #face_threshold]]

**(3.12) อัตราส่วนการเปิดตา (Eye Aspect Ratio)** EAR = (|p₂ − p₆| + |p₃ − p₅|) / (2|p₁ − p₄|) นับว่ากะพริบเมื่อ EAR ต่ำกว่า [[ใส่ค่าจาก Lab 15: เกณฑ์ EAR #ear_threshold]] แล้วกลับขึ้น (หรือใช้ค่า blendshape eyeBlink จาก Face Landmarker)

**(3.13) k เพื่อนบ้านใกล้ที่สุด (kNN)** เวกเตอร์ลักษณะ f = [normDist ของคู่จุดที่เลือก, curl 5 นิ้ว, spread] ระยะ D(f, g) = √Σ(fₖ − gₖ)² เลือก k = [[ใส่ค่าจาก Lab 31: ค่า k #knn_k]] ตัวอย่างที่ใกล้ที่สุด แล้วโหวตเสียงข้างมาก

**(3.14) ตัวชี้วัดการจำแนก** Accuracy = Σ TPᵢ / N; Precisionᵢ = TPᵢ/(TPᵢ + FPᵢ); Recallᵢ = TPᵢ/(TPᵢ + FNᵢ); F1ᵢ = 2PᵢRᵢ/(Pᵢ + Rᵢ)

**(3.15) สถิติพื้นฐาน** x̄ = Σxᵢ/n และ SD = √(Σ(xᵢ − x̄)² / (n − 1))

**(3.16) อัตราเฟรมและความสว่างภาพ** FPS = จำนวนเฟรม / เวลา (วินาที); ความสว่าง = ค่าเฉลี่ยของ 0.299R + 0.587G + 0.114B ทุกพิกเซล (0–255)

## 3.6 ประชากร กลุ่มตัวอย่าง และเกณฑ์การคัดเลือก

กลุ่มตัวอย่างคือผู้สูงอายุจำนวน [[ใส่ค่าจาก Lab 36: จำนวนผู้เข้าร่วม #n_participants]] คน เลือกแบบเจาะจง

**เกณฑ์การคัดเข้า (inclusion criteria)**
1. อายุ 60 ปีขึ้นไป
2. ขยับมืออย่างน้อยหนึ่งข้างได้ด้วยตนเอง
3. มองเห็นหน้าจอที่ระยะประมาณ 60 ซม. ได้ (สวมแว่นได้)
4. นั่งทำกิจกรรมต่อเนื่องได้อย่างน้อย 30 นาที
5. สื่อสารภาษาไทยได้ และลงนามในหนังสือแสดงความยินยอมด้วยตนเอง

**เกณฑ์การคัดออก (exclusion criteria)**
1. มีอาการบาดเจ็บ ปวด หรืออักเสบเฉียบพลันที่มือหรือข้อมือ หรือแพทย์ห้ามออกกำลังมือ
2. มีประวัติลมชักที่ไวต่อแสงกะพริบ
3. มีภาวะที่ไม่สามารถเข้าใจและให้ความยินยอมได้ด้วยตนเอง
4. เป็นสมาชิกทีม หรือเคยเห็น/ใช้งานระบบมาก่อน

**เกณฑ์การยุติการเข้าร่วม** ผู้เข้าร่วมขอหยุด รู้สึกเจ็บ ปวด หรือเหนื่อย ผู้สังเกตหยุดการทดสอบทันที

## 3.7 การวิเคราะห์ข้อมูล

ใช้ค่าร้อยละ ค่าเฉลี่ย และส่วนเบี่ยงเบนมาตรฐานตามสมการ (3.15) ความแม่นยำใช้สมการ (3.14) การแปลความหมายค่าเฉลี่ยความพึงพอใจใช้เกณฑ์ 4.51–5.00 = มากที่สุด, 3.51–4.50 = มาก, 2.51–3.50 = ปานกลาง, 1.51–2.50 = น้อย, 1.00–1.50 = น้อยที่สุด
