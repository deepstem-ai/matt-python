## 3.3 สมการและขั้นตอนวิธีที่ใช้

กำหนดให้ pᵢ = (xᵢ, yᵢ, zᵢ) คือจุดที่ i ของมือ (i = 0–20) ในพิกัดปรับค่า 0–1 จาก MediaPipe และ ‖·‖ คือระยะทางแบบยุคลิด 3 มิติ
เลขสมการ (1)–(10) ใช้เลขเดียวกับบทความวิชาการของทีม (MITIJ) สมการเสริมที่ไม่มีในบทความใช้เลข (11) เป็นต้นไป

### 3.3.1 การปรับค่าด้วยขนาดฝ่ามือ (Zarrat Ehsan, et al., 2026)

**สมการ (1) ขนาดฝ่ามือ** s = ‖p₀ − p₉‖ คำนวณใหม่ทุกเฟรม (ข้อมือถึงโคนนิ้วกลาง ซึ่งไม่งอตามท่ามือ)

**สมการ (2) ระยะปรับมาตรฐาน** d̂ᵢⱼ = ‖pᵢ − pⱼ‖ / s — เมื่อมือเข้าใกล้หรือออกห่างกล้อง ทั้งเศษและส่วนเปลี่ยนในสัดส่วนเดียวกัน d̂ จึงคงที่

**สมการ (3) คะแนนการจีบนิ้ว** π = clip( (d_open − d̂₄₈) / (d_open − d_close), 0, 1 ) เมื่อ d̂₄₈ คือระยะปลายนิ้วโป้งถึงปลายนิ้วชี้ตามสมการ (2) d_open และ d_close คือระยะขณะแบนิ้วและขณะจีบนิ้วของผู้ใช้แต่ละคน (จากการปรับเทียบ d_open = r, d_close = b; ก่อนปรับเทียบใช้ 0.80 และ 0.25) π = 1 หมายถึงจีบนิ้วสนิท

### 3.3.2 การกรองสัญญาณ One Euro Filter (Casiez, et al., 2012)

**สมการ (4)** α = 1 / (1 + 1/(2π f_c Tₑ)) เมื่อ Tₑ คือช่วงเวลาระหว่างเฟรม

**สมการ (5)** x̂ₜ = α xₜ + (1 − α) x̂ₜ₋₁ เมื่อ xₜ คือค่าดิบ และ x̂ₜ คือค่าที่ผ่านการกรอง

**สมการ (6)** f_c = f_c,min + β |ẋ̂ₜ| เมื่อ ẋ̂ₜ คืออัตราการเปลี่ยนแปลงที่ผ่านการกรองด้วยความถี่ตัด d_cutoff

พารามิเตอร์ f_c,min = [[ใส่ค่าจาก Lab 27: minCutoff #oe_mincutoff]] Hz, β = [[ใส่ค่าจาก Lab 27: beta #oe_beta]], d_cutoff = [[ใส่ค่าจาก Lab 27: dCutoff #oe_dcutoff]] Hz เมื่อมือนิ่ง f_c และ α ต่ำ สัญญาณจึงเรียบ เมื่อมือเคลื่อนที่เร็ว f_c สูงขึ้นและ α เข้าใกล้ 1 ระบบจึงตามทัน

### 3.3.3 การนับจำนวนครั้งแบบสองเกณฑ์ (Schmitt, 1938)

**สมการ (7)** ค้างท่า (held) ⇔ πₜ ≥ θ_on ; ปล่อยท่า (release) ⇔ πₜ ≤ θ_off ; θ_on > θ_off
ร่วมกับเครื่องสถานะ 5 สถานะ idle → engaging → held → releasing → cooldown ระบบนับหนึ่งครั้งเมื่อผ่านครบทุกสถานะ (ค้างอย่างน้อย [[ใส่ค่าจาก Lab 21: minHoldMs #rep_hold]] ms) และเว้นช่วง cooldown = [[ใส่ค่าจาก Lab 21: cooldownMs #rep_cooldown]] ms (บทความ ≈ 400 ms) ก่อนนับครั้งถัดไป ค่าที่ใช้ θ_on = [[ใส่ค่าจาก Lab 21: enter #rep_enter]], θ_off = [[ใส่ค่าจาก Lab 21: exit #rep_exit]]

### 3.3.4 การปรับเทียบรายบุคคล

**สมการ (8)** T = r − k(r − b), 0 < k < 1 เมื่อ r คือค่าขณะพัก และ b คือค่าที่ดีที่สุดของผู้ใช้ (เฉลี่ย 3 ครั้งที่ดีที่สุดจาก 5 ครั้ง) ใช้ k_on = 0.7 (เกณฑ์เข้าท่า) และ k_off = 0.3 (เกณฑ์ออกจากท่า) — ค่าที่ทีมใช้จริง [[ใส่ค่าจาก Lab 27: ค่า k เข้า/ออก ที่ใช้จริง #calib_k]]
เมื่อสร้างคะแนนด้วยสมการ (3) โดย d_open = r และ d_close = b จะได้ π(T) = k พอดี เกณฑ์ในหน่วยคะแนนจึงเป็น θ_on = 0.7 และ θ_off = 0.3 เท่ากันทุกคน
อาการมือสั่นวัดจากส่วนเบี่ยงเบนมาตรฐานของตำแหน่ง p₈ (หารด้วย s) ขณะวางมือนิ่ง [[ใส่ค่าจาก Lab 27: ระยะเวลาวัดขณะนิ่ง (วินาที) #tremor_sec]] วินาที แบ่ง 4 ระดับตามเกณฑ์ [[ใส่ค่าจาก Lab 27: ค่าแบ่งระดับอาการสั่น #tremor_cuts]] ระดับรุนแรงใช้การกรองแรงขึ้น (f_c,min ต่ำลง) และรัศมีการจับในเกมใหญ่ขึ้น
**กฎการวัดผล:** เมื่อใช้ระบบเพื่อวัดผล ต้อง "ตรึงเกณฑ์" (freeze thresholds) ไว้ตลอดการศึกษา เพื่อให้ผลแต่ละวันเปรียบเทียบกันได้ และบันทึกเกณฑ์ที่ใช้ไว้กับทุกเซสชัน

### 3.3.5 การเข้าสู่ระบบด้วยใบหน้า

**สมการ (9) ความคล้ายโคไซน์** cos θ = (A · B) / (‖A‖ ‖B‖) เมื่อ A คือเวกเตอร์จากจุดสำคัญบนใบหน้า 478 จุดขณะเข้าระบบ และ B คือเวกเตอร์ที่ลงทะเบียนไว้ (แอปบีบค่าให้อยู่ในช่วง 0–1 เพื่อแสดงผล) ยอมรับเมื่อ cos θ ≥ [[ใส่ค่าจาก Lab 15: เกณฑ์ความคล้าย #face_threshold]]

**สมการ (10) อัตราส่วนการเปิดตา (Soukupová and Čech, 2016)** EAR = (‖p₂ − p₆‖ + ‖p₃ − p₅‖) / (2 ‖p₁ − p₄‖) เมื่อ p₁–p₆ คือจุดรอบดวงตา (ตาขวา 33, 160, 158, 133, 153, 144; ตาซ้าย 362, 385, 387, 263, 373, 380) นับว่ากะพริบเมื่อ EAR ต่ำกว่า [[ใส่ค่าจาก Lab 15: เกณฑ์ EAR #ear_threshold]] แล้วกลับขึ้น ใช้ป้องกันการใช้ภาพถ่าย

ที่มาของสมการ: สมการ (4)–(6) จาก Casiez, et al. (2012) สมการ (10) จาก Soukupová and Čech (2016) สมการ (9) เป็นสูตรมาตรฐาน สมการ (7) ประยุกต์จากหลักการ hysteresis ของ Schmitt (1938) ส่วนสมการ (1)–(3) และ (8) ทีมออกแบบขึ้น โดยสมการ (1) และ (2) อาศัยแนวคิดของ Zarrat Ehsan, et al. (2026)

### 3.3.6 สมการเสริม (ไม่มีเลขในบทความ)

**(11) มุมที่ข้อต่อ** angle(A, B, C) = arccos( (u · v) / (|u| |v|) ) × 180/π เมื่อ u = A − B และ v = C − B

**(12) ความงอของนิ้ว** สำหรับนิ้ว (m, p, d, t) = (โคน, ข้อกลาง, ข้อปลาย, ปลายนิ้ว)
θ₁ = angle(p₀, pₘ, pₚ), θ₂ = angle(pₘ, pₚ, p_d), θ₃ = angle(pₚ, p_d, pₜ)
θ̄ = (0.5θ₁ + θ₂ + θ₃) / 2.5 และ curl = clamp((180 − θ̄) / 110, 0, 1); นิ้วโป้ง curl = clamp((180 − (θ₂ + θ₃)/2) / 70, 0, 1)

**(13) มุมกางนิ้วและคะแนนท่าอื่น** spread(a, b) = มุมระหว่างเวกเตอร์ (p_tip,a − p_mcp,a) และ (p_tip,b − p_mcp,b) เช่น นิ้วชี้ (p₅→p₈) กับนิ้วก้อย (p₁₇→p₂₀); คะแนนท่าอื่นใช้รูปแบบเดียวกับสมการ (3): กำมือ = clip((curl เฉลี่ย − 0.3)/(0.8 − 0.3)), แบมือกางนิ้ว = clip((spread − 20°)/(50° − 20°)) × ตัวคูณนิ้วเหยียด, งอ-เหยียดข้อมือ = clip((มุม (p₉ − p₀) กับแนวตั้ง − 10°)/(45° − 10°)) (ค่าเริ่มต้นใน js/gestures.js)

**(14) k เพื่อนบ้านใกล้ที่สุด (kNN)** เวกเตอร์ลักษณะ f = [d̂ ของคู่จุดที่เลือก, curl 5 นิ้ว, spread] ระยะ D(f, g) = √Σ(fₖ − gₖ)² เลือก k = [[ใส่ค่าจาก Lab 31: ค่า k #knn_k]] ตัวอย่างที่ใกล้ที่สุด แล้วโหวตเสียงข้างมาก

**(15) ตัวชี้วัดการจำแนก** Accuracy = Σ TPᵢ / N; Precisionᵢ = TPᵢ/(TPᵢ + FPᵢ); Recallᵢ = TPᵢ/(TPᵢ + FNᵢ); F1ᵢ = 2PᵢRᵢ/(Pᵢ + Rᵢ)

**(16) สถิติพื้นฐาน** x̄ = Σxᵢ/n และ SD = √(Σ(xᵢ − x̄)² / (n − 1))

**(17) อัตราเฟรมและความสว่างภาพ** FPS = จำนวนเฟรม / เวลา (วินาที); ความสว่าง = ค่าเฉลี่ยของ 0.299R + 0.587G + 0.114B ทุกพิกเซล (0–255); ความละเอียดของเวลาตอบสนอง ≈ 1000 / FPS มิลลิวินาที (≈ 33 ms ที่ 30 fps)

**(18) ความแม่นยำการนับ** Accuracyₛ = 1 − |N_ระบบ − N_ผู้สังเกต| / N_ผู้สังเกต และ MAE = Σ|N_ระบบ − N_ผู้สังเกต| / n

**(19) ICC (Shrout and Fleiss, 1979)** จากตาราง n คน × k ครั้ง: ICC(2,1) = (MSR − MSE) / (MSR + (k − 1)MSE + k(MSC − MSE)/n) และ ICC(3,1) = (MSR − MSE) / (MSR + (k − 1)MSE)

**(20) คะแนน SUS** SUS = 2.5 × [ Σ(ข้อคี่ − 1) + Σ(5 − ข้อคู่) ] ช่วง 0–100

## 3.5 ขั้นตอนการทดลองและการเก็บรวบรวมข้อมูล

**การทดลองที่ 1 ความแม่นยำในการจำแนกท่ามือ (Lab 32)** ระบบสุ่มลำดับท่าที่ขอให้ทำ ท่าละ [[ใส่ค่าจาก Lab 32: จำนวนครั้งต่อท่าต่อสภาพแสง #trials]] ครั้ง บันทึกท่าที่ขอและท่าที่ระบบตรวจได้ ข้อมูลทดสอบเป็นคนละชุดกับข้อมูลที่ใช้สอน AI ทดลองซ้ำใน 3 สภาพแสงโดยปรับไฟในห้องเองและบันทึกค่าความสว่างเฉลี่ยของภาพตามสมการ (17) ระยะมือถึงกล้อง [[ใส่ค่าจาก Lab 32: ระยะ (ซม.) #cam_distance]] ซม.

**การทดลองที่ 2 สมรรถนะบนหลายเครื่อง (Lab 33)** ทดสอบอัตโนมัติ 6 สถานการณ์ (กล้องอย่างเดียว ตรวจใบหน้า ตรวจมือแบบเรียบ แบบนีออน แบบหาง และเกมเต็ม) สถานการณ์ละ [[ใส่ค่าจาก Lab 33: วินาทีต่อสถานการณ์ #bench_sec]] วินาที บันทึก FPS เฉลี่ย FPS ต่ำสุด และเวลาประมวลผล AI ต่อเฟรม บนเครื่อง [[ใส่ค่าจาก Lab 33: จำนวนเครื่อง #n_machines]] เครื่อง เกณฑ์ผ่านตามแผนการประเมินของบทความ คือ FPS เฉลี่ย ≥ 25 ภาพต่อวินาทีในทุกสถานการณ์และทุกแพลตฟอร์ม (หน้า Lab 33 แสดง PASS/FAIL ต่อสถานการณ์และภาพรวม)

**การทดลองที่ 3 การเข้าสู่ระบบด้วยใบหน้า (Lab 15)** ผู้ใช้ที่ลงทะเบียนแล้วเข้าระบบ [[ใส่ค่าจาก Lab 15: จำนวนครั้งที่ทดสอบ #face_n]] ครั้ง บันทึกผลถูก/ผิด และเวลาที่ใช้ รวมทั้งทดสอบบุคคลอื่นและภาพถ่ายที่ต้องถูกปฏิเสธ

**การทดลองที่ 4 ตัวกรองสัญญาณ (Lab 27)** บันทึกตำแหน่งปลายนิ้วชี้ขณะวางมือนิ่ง เปรียบเทียบสัญญาณดิบกับ One Euro, ค่าเฉลี่ยเคลื่อนที่ และมัธยฐาน คำนวณร้อยละการลดการสั่นและความหน่วง (ms)

**การทดลองที่ 5 การทดสอบกับผู้สูงอายุ (Lab 36)** ผู้เข้าร่วมลงนามยินยอมก่อนเริ่ม ทำงาน 8 อย่างด้วยตนเองโดยผู้สังเกตไม่ช่วยเหลือ บันทึกผล (ทำได้เอง / ต้องช่วย / ทำไม่ได้) และเวลา จากนั้นตอบแบบสอบถาม 10 ข้อ มาตรประมาณค่า 5 ระดับ และแบบวัด System Usability Scale (SUS) มาตรฐาน 10 ข้อ (สมการ 20) ใช้เวลาคนละประมาณ 20–30 นาที ระหว่างวันที่ [[ใส่ค่าจาก Lab 36: ช่วงวันที่ทดสอบ #test_dates]]

**การทดลองที่ 6 ความถูกต้องของการนับจำนวนครั้ง (Lab 32 · ความแม่นยำการนับ)** อัดวิดีโอขณะผู้เข้าร่วมเล่นเกม ผู้สังเกตนับจำนวนครั้งจากวิดีโอโดยไม่เห็นตัวเลขของระบบ แล้วเปรียบเทียบกับจำนวนที่ระบบนับได้ภายใต้ระดับแสง 3 ระดับ (สว่าง ปกติ มืด พร้อมค่าความสว่างที่วัดได้) คำนวณความแม่นยำร้อยละและ MAE ตามสมการ (18) เกณฑ์ทั้งหมดถูกตรึงไว้ตลอดการทดลอง

**การทดลองที่ 7 ความเที่ยงของการวัดซ้ำ (Lab 32 · ICC)** ผู้เข้าร่วมแต่ละคนเล่นเกมเดิมซ้ำหลายวันโดยใช้เกณฑ์ที่ตรึงไว้ ไม่นำผลรอบแรกมาวิเคราะห์เนื่องจากได้รับผลจากการฝึก (Kim, et al., 2025) คำนวณ ICC(2,1) และ ICC(3,1) ตามสมการ (19) จากเซสชันที่ 2 เป็นต้นไป ถือว่า ICC ≥ 0.75 อยู่ในระดับดี (Koo and Li, 2016) ต้องลบข้อมูลสาธิตออกจากเครื่องก่อนเก็บข้อมูลจริง

ข้อมูลทั้งหมดส่งออกเป็นไฟล์ CSV และเก็บในโฟลเดอร์ evidence ตามรายการใน evidence/SUMMARY.md

## 3.6 ประชากร กลุ่มตัวอย่าง และเกณฑ์การคัดเลือก

กลุ่มตัวอย่างคือผู้สูงอายุจำนวน [[ใส่ค่าจาก Lab 36: จำนวนผู้เข้าร่วม #n_participants]] คน เลือกแบบเจาะจง

**เกณฑ์การคัดเข้า (inclusion criteria)**
1. อายุ 60 ปีขึ้นไป
2. ขยับมืออย่างน้อยหนึ่งข้างได้ด้วยตนเอง
3. มองเห็นหน้าจอที่ระยะประมาณ 60 ซม. ได้ (สวมแว่นได้)
4. นั่งทำกิจกรรมต่อเนื่องได้อย่างน้อย 30 นาที
5. สื่อสารภาษาไทยได้ และลงนามในหนังสือแสดงความยินยอมด้วยตนเอง

**เกณฑ์การคัดออก (exclusion criteria)**
1. มีอาการบาดเจ็บ ปวด หรืออักเสบเฉียบพลันที่มือหรือข้อมือ หรือแพทย์ห้ามออกกำลังมือ
2. มีประวัติลมชักที่ไวต่อแสงกะพริบ
3. มีภาวะที่ไม่สามารถเข้าใจและให้ความยินยอมได้ด้วยตนเอง
4. เป็นสมาชิกทีม หรือเคยเห็น/ใช้งานระบบมาก่อน

**เกณฑ์การยุติการเข้าร่วม** ผู้เข้าร่วมขอหยุด รู้สึกเจ็บ ปวด หรือเหนื่อย ผู้สังเกตหยุดการทดสอบทันที

## 3.7 การวิเคราะห์ข้อมูล

ใช้ค่าร้อยละ ค่าเฉลี่ย และส่วนเบี่ยงเบนมาตรฐานตามสมการ (16) ความแม่นยำการจำแนกใช้สมการ (15) การแปลความหมายค่าเฉลี่ยความพึงพอใจใช้เกณฑ์ 4.51–5.00 = มากที่สุด, 3.51–4.50 = มาก, 2.51–3.50 = ปานกลาง, 1.51–2.50 = น้อย, 1.00–1.50 = น้อยที่สุด

แผนการประเมิน 4 ด้านตามบทความ (หัวข้อ 6.2):
1. **ประสิทธิภาพ** อัตราเฟรม ≥ 25 ภาพต่อวินาทีในทุกสถานการณ์และทุกแพลตฟอร์ม (การทดลองที่ 2)
2. **ความถูกต้อง** เปรียบเทียบจำนวนครั้งที่ระบบนับกับการนับจากวิดีโอโดยผู้สังเกต ภายใต้ระดับแสง 3 ระดับ รายงานความแม่นยำร้อยละและ MAE (การทดลองที่ 6, สมการ 18)
3. **ความเที่ยงของการวัดซ้ำ** ICC ≥ 0.75 = ดี (Koo and Li, 2016) ไม่นับรอบแรก (Kim, et al., 2025) แปลผล < 0.50 ต่ำ, 0.50–0.75 ปานกลาง, 0.75–0.90 ดี, > 0.90 ดีมาก (การทดลองที่ 7, สมการ 19)
4. **ความสามารถในการใช้งาน** คะแนน SUS เฉลี่ย ± SD เปรียบเทียบกับค่า 68 (Acharya, et al., 2025) (การทดลองที่ 5, สมการ 20)

การประเมินที่มีผู้เข้าร่วมวิจัยดำเนินการหลังได้รับการรับรองจริยธรรม
