# รายการของที่ต้องนำไปวันนำเสนอ — HandRehab Arcade

> ตรวจคืนก่อนวันงาน 1 วัน และตรวจอีกครั้งก่อนออกจากโรงเรียน · ★ = ของที่คนส่วนใหญ่ลืม

## ของจำเป็น (ขาดไม่ได้)

- [ ] โน้ตบุ๊กหลัก — แอปติดตั้งแล้ว เปิดได้แบบออฟไลน์ แบตเต็ม
- [ ] สายชาร์จโน้ตบุ๊กหลัก
- [ ] ★ ปลั๊กพ่วง / สายต่อไฟยาว 3–5 เมตร (ปลั๊กในห้องมักอยู่ไกลโต๊ะ)
- [ ] ★ หัวแปลง HDMI และ USB-C → HDMI (และ VGA ถ้าโปรเจกเตอร์เก่า)
- [ ] สาย HDMI ยาว
- [ ] ★ เมาส์ (ทัชแพดบนเวทีใช้ยาก และใช้เป็นโหมดสาธิตสำรองได้)
- [ ] เว็บแคมหลัก (ถ้าไม่ใช้กล้องในตัว) — ตั้งค่าความละเอียดเดียวกับที่ทดลอง
- [ ] ★ USB drive ที่มี: ชุดแอปออฟไลน์ครบ (รวมไฟล์โมเดล) · สไลด์ PDF · วิดีโอสาธิต 2 นาที · โฟลเดอร์ evidence
- [ ] ★ วิดีโอสาธิตสำรอง เปิดค้างไว้ในแท็บที่สองของเบราว์เซอร์ และมีในมือถือด้วย
- [ ] ★ หนังสือยินยอมฉบับจริงที่เซ็นแล้ว 5 ฉบับ ใส่แฟ้ม (กรรมการอาจขอดู)
- [ ] รายงานฉบับพิมพ์ 1 ชุด + evidence/SUMMARY.md ฉบับพิมพ์ (บัตรคำตอบตัวเลข)
- [ ] บทพูด (pitch.md) และคำตอบ 15 ข้อ (qa-prep.md) ฉบับพิมพ์ย่อ

## ของสำรอง (มีแล้วอุ่นใจ)

- [ ] ★ เว็บแคมสำรอง 1 ตัว + สาย USB ต่อยาว
- [ ] ★ โคมไฟตั้งโต๊ะ LED (ห้องประกวดมักมืดกว่าห้องเรียน)
- [ ] โน้ตบุ๊กเครื่องที่ 2 ติดตั้งแอปไว้แล้ว + สายชาร์จของเครื่องนั้น
- [ ] USB drive อันที่ 2 (สำเนาเหมือนอันแรก)
- [ ] ฮอตสปอตมือถือ (เผื่อจำเป็นต้องใช้เน็ต แม้แอปไม่ต้องใช้)
- [ ] สไลด์ฉบับพิมพ์ย่อ 1 ชุด (ถ้าจอดับทั้งหมด)
- [ ] ตัวแปลงปลั๊ก 3 ขา → 2 ขา
- [ ] เทปกาว / ที่หนีบ (ยึดสายกล้อง กันสะดุด)
- [ ] ทิชชู่เปียกเช็ดเลนส์กล้อง
- [ ] การ์ด QR ลิงก์โครงงาน (ของแจก ถ้ามี)
- [ ] น้ำดื่ม (พูด 5 นาทีคอแห้ง)

## เช้าวันงาน (ตรวจก่อนขึ้นเวที 15 นาที)

- [ ] ต่อจอแล้ว เห็นภาพบนโปรเจกเตอร์
- [ ] ปิดการแจ้งเตือนทั้งหมด (โหมดห้ามรบกวน / Focus assist) และปิดโปรแกรมแชต
- [ ] เปิดแอปค้างที่หน้าเข้าระบบ · ลงทะเบียนใบหน้าผู้สาธิตใหม่ในแสงของห้องนั้น
- [ ] ทดสอบกล้องและแสง ถ้ามืด เปิดโคมไฟ
- [ ] แท็บที่สอง: วิดีโอสาธิตพร้อมเล่น
- [ ] ปิดหน้าจอวินิจฉัย/FPS ทั้งหมด เหลือเฉพาะสิ่งที่ผู้ชมควรเห็น
- [ ] เปิดนาฬิกาซ้อม (index.html) ในมือถือของคนที่ 1 เพื่อดูเวลา
