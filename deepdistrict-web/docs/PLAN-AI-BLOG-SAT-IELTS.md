## 2. บล็อกข่าวอัตโนมัติด้วย AI

### 2.1 สองโหมด

1. **โหมดสั่งงาน:** คุณกรอก **หัวข้อ + ขอบเขต** แล้ว AI ทำงานดังนี้
   - ค้นข้อมูลล่าสุดจากแหล่งที่อนุญาต
   - เขียนร่าง TH/EN พร้อมแหล่งอ้างอิง
   - ส่งร่างเข้าคิว "รอตรวจ"
2. **โหมดอัตโนมัติ:** cron (ใช้ URL `/api/cron` เดิม) รันตามรอบที่ตั้งไว้ เช่น จันทร์/พฤหัส แล้ว AI ทำงานดังนี้
   - เสนอหัวข้อจากหมวดที่คุณกำหนด เช่น TCAS, SAT, IELTS, AI/STEM, ทุนการศึกษา
   - เขียนร่าง แล้วทำอย่างใดอย่างหนึ่ง
     - ส่งเข้าคิวรอตรวจ (ค่าเริ่มต้น)
     - โพสต์เองทันที ถ้าหมวดนั้นตั้งค่าเป็น "auto-publish"

### 2.2 ขั้นตอนของบทความ (สถานะเก็บในฐานข้อมูล)

`idea → drafting → review → scheduled → published → archived` (มี `rejected` แยก)

- ทุกการเปลี่ยนสถานะบันทึกลง audit: ใคร, เมื่อไร, จากสถานะไหน
- เก็บ prompt, แหล่งข้อมูล, และค่าใช้จ่าย AI ของแต่ละบทความ (ตาราง `ai_jobs`)

### 2.3 กติกาความถูกต้องและความปลอดภัย

- **ต้องมีแหล่งอ้างอิง:** ทุกข้อเท็จจริงที่เป็นตัวเลข วันที่ หรือเกณฑ์ต้องมีลิงก์แหล่งที่มา ถ้าไม่มีลิงก์ ระบบจะไม่ยอมให้เผยแพร่
- **แหล่งที่อนุญาต (allowlist)** คุณแก้ได้ในหลังบ้าน เช่น
  - mytcas.com
  - collegeboard.org
  - ielts.org
  - เว็บมหาวิทยาลัย
  - อว.
- **เขียนด้วยสำนวนของเราเอง:**
  - ไม่คัดลอกข้อความ
  - อ้างอิงได้สั้นๆ พร้อมเครดิต
  - ไม่ใช้รูปของผู้อื่น
  - ใช้ภาพที่สร้างเอง หรือภาพที่มีสิทธิ์ใช้
- **ป้ายกำกับ AI:** ทุกบทความแสดงข้อความ "เรียบเรียงด้วย AI · ตรวจทานโดยทีม DeepDistrict" พร้อมวันที่ตรวจล่าสุด
  - ถ้าเป็นโพสต์โปรโมชัน ให้ทำตามแนวทาง สคบ. เรื่องการระบุเนื้อหา/ภาพที่สร้างด้วย AI ในโฆษณา
- **หัวข้อต้องห้าม:** แก้ได้ในหลังบ้าน เช่น ข่าวลือข้อสอบรั่ว และการรับประกันผลสอบ
- **งบประมาณ:** กำหนดเพดานค่า AI ต่อเดือน ถ้าเกินเพดาน ระบบจะหยุดโหมดอัตโนมัติเองแล้วแจ้งเตือนแอดมิน

### 2.4 ส่วนที่ผู้ใช้เห็น

- หน้า `/blog` มีรายการบทความ, ตัวกรองตามหมวด, และหน้าอ่านบทความ (มีคำอธิบายสำหรับ SEO และใช้ได้ดีบนมือถือ)
- ปุ่ม "แจ้งเตือนเมื่อมีโพสต์ใหม่" ส่งผ่านระบบแจ้งเตือน/LINE ที่มีอยู่แล้ว
- เชื่อมกับป๊อปอัปได้ เช่น ใช้โปรโมทบทความเด่น

## 3. SAT Reading & Writing — ตามรูปแบบสอบจริง (Digital SAT)

| กฎ | ค่าที่ระบบบังคับ |
| --- | --- |
| โครงสร้าง | 2 โมดูล × 27 ข้อ × 32 นาที (รวม 54 ข้อ / 64 นาที) |
| ข้อทดลอง | ในข้อสอบจริง แต่ละโมดูลมีข้อทดลองที่ไม่นับคะแนน (pretest) 2 ข้อ ปนอยู่โดยผู้สอบไม่รู้ว่าข้อไหน ระบบเราจะรองรับการติดป้าย "unscored" ให้ข้อได้ ไว้ใช้ทดลองข้อใหม่ |
| ลักษณะข้อ | 1 บทอ่านสั้น (25–150 คำ) ต่อ 1 ข้อ, ปรนัย 4 ตัวเลือก, ไม่หักคะแนนเมื่อตอบผิด |
| 4 ด้านเนื้อหา | Craft & Structure · Information & Ideas · Standard English Conventions · Expression of Ideas |
| ลำดับข้อในโมดูล | จัดกลุ่มตามประเภททักษะ และในแต่ละกลุ่มเรียงจากง่ายไปยาก |
| Adaptive (MST) | โมดูล 1 เหมือนกันทุกคน, โมดูล 2 เลือกชุดง่ายหรือยากตามผลโมดูล 1 |
| การเดินในข้อสอบ | ย้อนกลับ/ทำเครื่องหมาย "Mark for Review" ได้เฉพาะในโมดูลเดียวกัน, หมดเวลาแล้วย้ายโมดูลอัตโนมัติ และย้อนกลับโมดูลเดิมไม่ได้ |
| เครื่องมือบนจอ | ตัวจับเวลา (ซ่อนได้), เน้นข้อความ/โน้ต, ตัดตัวเลือก, หน้าสรุปข้อที่ทำแล้ว |
| คะแนน | ช่วง 200–800 (เป็น **ค่าประมาณของเรา** ไม่ใช่ตารางทางการ) และถ้าได้ชุดง่ายในโมดูล 2 จะมีเพดานคะแนน |

**คลังข้อสอบขั้นต่ำต่อ 1 ชุด MST:** โมดูล 1 (27 ข้อ) + โมดูล 2 ง่าย (27 ข้อ) + โมดูล 2 ยาก (27 ข้อ) = **81 ข้อ**

- เป้าแรก: **300+ ข้อ** เพื่อสุ่มได้หลายชุดโดยไม่ซ้ำ

## 4. IELTS Academic Reading

| กฎ | ค่าที่ระบบบังคับ |
| --- | --- |
| โครงสร้าง | 60 นาที · 3 บทอ่าน (รวมประมาณ 2,150–2,750 คำ) · 40 ข้อ · ไม่มีเวลาโอนคำตอบเพิ่ม |
| ประเภทคำถาม | Multiple choice (คำตอบเดียว 3–5 ตัวเลือก และแบบเลือก TWO/THREE ตัวอักษร คิดคะแนนตัวละ 1) · True/False/Not Given · Yes/No/Not Given · Matching information / headings / features / sentence endings · Summary แบบเลือกคำจากกล่อง · Sentence / summary / note / table / flow-chart completion · Diagram labelling · Short answer |
| การตรวจคำตอบ | ตรวจตัวสะกด, ตรวจจำนวนคำตามคำสั่ง (เช่น "NO MORE THAN TWO WORDS"), ยอมรับคำตอบทางเลือกที่ครูกำหนดไว้ |
| หน้าจอ | บทอ่านอยู่ซ้าย คำถามอยู่ขวา (แบบ computer-delivered), เน้นข้อความได้ |
| คะแนน | 40 ข้อแปลงเป็น band 0–9 ด้วย **ตารางประมาณการของเรา** (ทางการไม่ได้เผยแพร่ตารางตายตัว) |

## 5. IELTS Academic Writing

| กฎ | ค่าที่ระบบบังคับ |
| --- | --- |
| เวลา | 60 นาทีรวม (แนะนำ Task 1 ประมาณ 20 นาที, Task 2 ประมาณ 40 นาที) |
| Task 1 | บรรยายกราฟ/ตาราง/แผนภาพ/กระบวนการ อย่างน้อย 150 คำ |
| Task 2 | เรียงความแสดงความเห็น/อภิปราย อย่างน้อย 250 คำ |
| เครื่องเขียน | นับคำสดแบบเดียวกับข้อสอบคอม, ไม่มีตัวตรวจคำสะกด, บันทึกร่างอัตโนมัติ, ส่งเมื่อหมดเวลา |
| เกณฑ์ 4 ด้าน | Task Achievement/Response · Coherence & Cohesion · Lexical Resource · Grammatical Range & Accuracy |
| น้ำหนัก | Task 2 มีน้ำหนักเป็น 2 เท่าของ Task 1 · 4 เกณฑ์น้ำหนักเท่ากัน · เขียนสั้นกว่าขั้นต่ำอาจมีหลักฐานไม่พอสำหรับ band สูง (ทางการไม่ได้ระบุการหักคะแนนตายตัว) · ออกนอกเรื่อง เขียนเป็นข้อ ๆ ลอก หรือท่องจำทั้งฉบับ ถูกลงโทษ |
| การให้คะแนน | AI เสนอ band รายเกณฑ์ พร้อมเหตุผลและจุดแก้ จากนั้น **ครูยืนยัน/แก้ไข** ก่อนนักเรียนเห็นคะแนน "ทางการของสถาบัน" ส่วนโหมดฝึกเอง แสดงผล AI ได้ทันทีโดยติดป้าย "ประมาณการ" |

> ต้องยืนยันรายละเอียดทุกข้อในตารางกับ band descriptors ฉบับล่าสุดจาก ielts.org ก่อนเปิดใช้จริง

## 7. สิ่งที่คุณต้องเตรียม (เริ่มได้ทันที)

### ต้องมีก่อนเริ่ม Phase 0
1. **คีย์ Claude API:** สมัครที่ console.anthropic.com แล้วตั้งเพดานงบรายเดือน
   - ใส่คีย์ใน environment/secret ของเซิร์ฟเวอร์เท่านั้น **ห้ามส่งในแชต**
2. **PythonAnywhere Developer** (ประมาณ $10/เดือน) เพราะบัญชีฟรีออกอินเทอร์เน็ตได้แบบจำกัด และไม่มี scheduled tasks
3. **ยืนยันแนวทาง:** ต่อยอดแอปเดิม (แนะนำ: ล็อกอินเดียว ระบบเดียว) หรือแยกไป Django

### สำหรับบล็อก
4. **หมวดบทความ 5–8 หมวด** เช่น TCAS, SAT, IELTS, แพทย์/กสพท, AI-STEM, ทุน, ข่าวสถาบัน
5. **ขอบเขตและเรื่องต้องห้าม** และรายชื่อเว็บที่เชื่อถือได้ (allowlist)
6. **โทนภาษา:** สุภาพ/เป็นกันเอง ความยาวประมาณกี่คำ และ TH อย่างเดียวหรือ TH+EN
7. **ความถี่และผู้ตรวจ:** โพสต์สัปดาห์ละกี่ครั้ง ใครเป็นคนกดอนุมัติ และหมวดไหนยอมให้โพสต์อัตโนมัติ

### สำหรับข้อสอบ
8. **ครูภาษาอังกฤษ 1–2 คน** สำหรับตรวจข้อ/ให้คะแนน Writing (ประมาณ 3–5 ชม./สัปดาห์ในช่วงสร้างคลัง)
9. **ตัวอย่างข้อที่เราแต่งเอง** ด้านละ 5–10 ข้อ เป็นแบบอย่างสไตล์ให้ AI
   - SAT ทั้ง 4 ด้าน และ IELTS Reading ทุกประเภทคำถาม
   - IELTS Writing Task 1 + Task 2 อย่างละ 2–3 โจทย์ พร้อมเรียงความตัวอย่าง band 6/7/8
10. **ตัดสินใจเรื่องคะแนน:** ใช้ตารางแปลงคะแนนประมาณการของเรา (ระบบมีค่าเริ่มต้นให้ ครูปรับได้)
11. **นักเรียนนำร่อง 5–10 คน** สำหรับทดลองสอบจริง เพื่อเก็บสถิติความยากของข้อ

### เอกสารและกฎหมาย
12. ให้ผู้ดูแลกฎหมายตรวจข้อความในหัวข้อ 6 รวมถึงป้าย AI และเงื่อนไขการใช้งานสำหรับนักเรียน (ผู้เยาว์ต้องได้รับความยินยอมจากผู้ปกครองตาม PDPA เดิม)

## 8. สิ่งที่ระบบจะสร้าง (สำหรับทีมพัฒนา)

- **ไฟล์ใหม่**
  - `server/ai.py` — ตัวเชื่อม AI, คิว `ai_jobs`, เพดานงบ, retry
  - `server/blog.py` — CRUD และ workflow สถานะ, ตรวจลิงก์อ้างอิง, ตั้งเวลา
  - `server/exams/` — คลังข้อ, blueprint, form, attempt, คะแนน
- **หลังบ้าน**
  - เมนู "บล็อก": สั่งงาน AI, คิวรอตรวจ, ปฏิทินโพสต์
  - เมนู "คลังข้อสอบ": นำเข้า/ร่างด้วย AI/อนุมัติ, สร้างชุดสอบ
  - เมนู "ตรวจ Writing"
- **ฝั่งนักเรียน**
  - หน้าสอบเต็มจอ แยกตามแบบ SAT และแบบ IELTS
  - หน้ารายงานคะแนนรายทักษะ
- **ความปลอดภัย**
  - เฉลยไม่ส่งไปที่เครื่องนักเรียน (ตรวจที่เซิร์ฟเวอร์)
  - จับเวลาฝั่งเซิร์ฟเวอร์
  - เก็บ log ทุกการกระทำ
- **ทดสอบ:** ชุดทดสอบอัตโนมัติสำหรับกฎทุกข้อในตารางหัวข้อ 3–5 เช่น จำนวนข้อ เวลา การล็อกโมดูล การนับคำ และการตรวจจำนวนคำในคำตอบ
