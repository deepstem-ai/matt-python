# ทดสอบบนคอมพิวเตอร์ของตัวเองก่อนขึ้นเซิร์ฟเวอร์จริง (v5.7 r1)

คู่มือนี้ใช้ตรวจทุกระบบใหม่บนเครื่องของคุณ ทั้งหมดทำงานได้โดยไม่ต้องมีอินเทอร์เน็ต ยกเว้นส่วนที่ใช้ AI (ดูข้อ 7)

## 1. เตรียมเครื่อง (ครั้งเดียว)

1. ติดตั้ง **Python 3.10 ขึ้นไป** จาก python.org
   - Windows: ตอนติดตั้งให้ติ๊ก "Add python.exe to PATH"
2. แตกไฟล์ `deepdistrict-web-v5.6-r1.zip` ไว้ในโฟลเดอร์ใหม่
   - **อย่าแตกทับเวอร์ชันเก่า** ระบบเก็บข้อมูลไว้ใน `server/data` ของแต่ละโฟลเดอร์
3. ถ้ามีข้อมูลในเวอร์ชันเก่า ให้ย้ายมาด้วยวิธีนี้:
   1. เปิดเวอร์ชันเก่า
   2. ไปที่ ตั้งค่า → ส่งออกข้อมูลสำรอง
   3. เปิดเวอร์ชันใหม่ แล้วไปที่ ตั้งค่า → นำเข้าข้อมูลสำรอง

## 2. เปิดระบบ

- **Windows:** ดับเบิลคลิก `start.bat`
- **macOS/Linux:** เปิด Terminal ในโฟลเดอร์นั้น แล้วพิมพ์ `./start.sh`

เบราว์เซอร์จะเปิดเอง ที่ `http://localhost:8000`

- ถ้าพอร์ต 8000 ไม่ว่าง ระบบจะใช้พอร์ตถัดไปเอง ให้ดูหมายเลขพอร์ตในหน้าต่างดำ
- ปิดระบบด้วย Ctrl + C ในหน้าต่างดำ

ทดสอบห้องเรียนสดกับมือถือ/แท็บเล็ตจริงในวง Wi-Fi เดียวกัน:

1. เปิดระบบด้วย `start.bat --lan` (หรือ `./start.sh --lan`)
2. ในมือถือ เปิด `http://<IP ของคอมพิวเตอร์>:8000`

## 3. ตั้งค่าเริ่มต้น (5 นาที)

1. เปิด `http://localhost:8000/admin/` แล้วสร้างบัญชีผู้ดูแล (admin)
2. ไปที่ **ผู้ใช้และนักเรียน**
   - เพิ่มครู 1 คน
   - เพิ่มนักเรียน 2–3 คน ใส่อีเมลและรหัสผ่านให้ทุกคน
3. ไปที่ **คลังข้อสอบ** → **โหลดข้อสอบตัวอย่าง** (ได้ 11 ข้อ)

ใช้ **หน้าต่างไม่ระบุตัวตน (Incognito)** หรือเบราว์เซอร์อีกตัว เพื่อเข้าสู่ระบบเป็นครูและนักเรียนพร้อมกันได้

## 4. ชุดข้อสอบ + ห้องเรียนสด (ใช้ข้อสอบชุดเดียวกันทั้งหมด)

1. **ครู:** เมนู **ชุดข้อสอบ** → **สร้างชุดข้อสอบ**
   1. ตั้งชื่อ เช่น "SAT สัปดาห์ 3" และใส่ห้อง เช่น "ม.5/2"
   2. เลือกจำนวน 4–5 ข้อ แล้วบันทึก
2. **ก่อนเรียน:**
   - กด **PDF นักเรียน (ช่องโน้ต)** → ทุกข้อต้องมีช่อง NOTES ข้าง ๆ และ**ไม่มีเฉลย**
   - กด **PDF ครู (เฉลย)** → ต้องเป็นข้อเดียวกัน ลำดับตัวเลือกเดียวกัน และมีเฉลย
3. **ห้องเรียนสดแบบ "ครูพาทำทีละข้อ":**
   1. ครูกด **▶ เปิดห้องเรียนสด** → เลือก "ครูพาทำทีละข้อ" → จะได้**แผงครู**
   2. กด **เปิดจอสำหรับแชร์ ↗** จะได้อีกหน้าต่าง ให้แชร์เฉพาะหน้าต่างนี้ใน Zoom
   3. นักเรียน (Incognito หรือมือถือ): **ข้อสอบออนไลน์** → **เข้าห้องเรียนสด** → พิมพ์รหัส
   4. ครูกด เปิดรับคำตอบ → ปิดรับคำตอบ → เฉลย → ข้อถัดไป
   - [ ] จอสำหรับแชร์**ต้องไม่มีเฉลยและไม่มีชื่อนักเรียน**จนกว่าครูจะกดเฉลย
   - [ ] แผงครูต้องเห็นเฉลย และตารางว่าใครตอบอะไร ถูกหรือผิด
   - [ ] ลำดับตัวเลือกในห้องต้องตรงกับใน PDF
4. **ห้องเรียนสดแบบ "นักเรียนทำเองทั้งชุด":**
   1. เปิดห้องใหม่ด้วยแบบนี้ ใส่เวลา เช่น 10 นาที แล้วกด **เริ่ม**
   2. นักเรียนทำข้อไหนก่อนก็ได้ และแก้คำตอบได้จนกว่าครูปิดรับ
   - [ ] ตารางของครูต้องอัปเดตสด และแสดง % ถูกของแต่ละข้อ (แตะหัวคอลัมน์เพื่อดูข้อนั้น)
   - [ ] จอสำหรับแชร์ต้องแสดงความคืบหน้ารวมเท่านั้น
   - [ ] หมดเวลาแล้วระบบต้องปิดรับคำตอบเอง
   3. ครูกด **ปิดรับคำตอบ** → **เฉลย**
   - [ ] นักเรียนต้องเห็นคะแนนและเฉลยทุกข้อ
   4. ครูกด **ข้อถัดไป** เพื่ออธิบายทีละข้อ
   - [ ] จอแชร์ต้องเปลี่ยนตามที่ครูกด
5. **สลับตัวเลือก:**
   1. ที่ชุดข้อสอบ กด **⇄ สลับตัวเลือกใหม่**
   2. พิมพ์ PDF ใหม่
   - [ ] ต้องเป็นข้อเดิม แต่ลำดับ A–D เปลี่ยน และ PDF ระบุ "Version 2"
   - [ ] PDF ที่พิมพ์ไปก่อนหน้ายังคงเป็นลำดับเดิม
   3. ให้นักเรียนทำข้อสอบออนไลน์ 2 รอบ
   - [ ] ลำดับตัวเลือกของแต่ละรอบต้องไม่เหมือนกัน

## 5. PDF ที่มีบันทึกว่าใครสร้าง เมื่อไร

1. **ครู:** เมนู **เอกสาร PDF** → **สร้างชุดข้อสอบ PDF**
   1. เลือก SAT จำนวน 6 ข้อ ใส่ชื่อชุดและห้องเรียน
   2. ติ๊ก **ฉบับครู มีเฉลย**
   3. กดสร้าง → ไฟล์ PDF ดาวน์โหลดทันที
2. **เปิดไฟล์ PDF แล้วตรวจว่ามีครบ:**
   - [ ] โลโก้และชื่อชุดข้อสอบ
   - [ ] **รหัสตรวจสอบ** (DD-XXXX-XXXX) และ QR code
   - [ ] ใครสร้าง (ชื่อ/บทบาท) และวันเวลาที่สร้าง และฉบับนี้พิมพ์เมื่อไรโดยใคร
   - [ ] กรอบ "วิธีใช้" และกรอบ "ขอบเขตทางกฎหมาย" (ลิขสิทธิ์ ห้ามเผยแพร่ เครื่องหมายการค้า)
   - [ ] ท้ายทุกหน้ามีรหัส วันเวลา และเลขหน้า และมีลายน้ำรหัสจาง ๆ
   - [ ] ฉบับครูมีคำว่า **TEACHER COPY** ทุกหน้า และหน้าเฉลยเริ่มหน้าใหม่
3. **หน้า เอกสาร PDF:**
   - [ ] เห็นรายการที่สร้าง และบันทึกทุกครั้งที่ดาวน์โหลด
   - [ ] กด **ดาวน์โหลดอีกครั้ง** แล้วต้องได้ข้อสอบชุดเดิม (แม้จะแก้ข้อสอบในคลังไปแล้ว)
4. **ตรวจความถูกต้องของเอกสาร:** เปิด `http://localhost:8000/pages/verify.html` (หรือสแกน QR ด้วยมือถือในโหมด `--lan`) แล้วใส่รหัส
   - [ ] ต้องขึ้น "เอกสารของ DeepDistrict ที่ถูกต้อง"
   - [ ] ชื่อผู้สร้างต้องถูกปิดบางส่วน
   - [ ] หน้านี้ต้องไม่แสดงข้อสอบ
5. **ผู้ดูแล:** กด **ยกเลิก** เอกสาร → หน้า verify ต้องขึ้นว่า "ถูกยกเลิกแล้ว"
6. **นักเรียน:** ทำข้อสอบฝึกให้จบ → หน้าผลสอบกด **ดาวน์โหลดรายงานผลสอบ (PDF)**
   - [ ] รายงานต้องมีรหัสตรวจสอบและ QR เช่นกัน

## 6. ปรับระดับความยากจากผลสอบจริง

1. **ผู้ดูแล:** **คลังข้อสอบ** → กรอบ **ผลสอบจริงและระดับความยาก** → **เปลี่ยน** → ตั้งขั้นต่ำเป็น **3** (เฉพาะตอนทดลอง ใช้งานจริงควรเป็น 20–30)
2. ให้นักเรียน 3 คนทำ SAT แบบฝึกตามหัวข้อ หรือเล่นห้องเรียนสดด้วยกัน (คำตอบในห้องเรียนสดก็นับ)
3. กลับมาที่คลังข้อสอบ แต่ละข้อจะแสดง:
   - `n` = จำนวนผู้ตอบ
   - `p` = % ผู้ตอบถูก
   - `r` = ค่าอำนาจจำแนก
   - **แนะนำ: ง่าย/กลาง/ยาก**
   - ป้ายเตือน เช่น "ยากมาก — ตรวจเฉลย"
4. กด **ปรับ** ทีละข้อ หรือ **ปรับตามคำแนะนำทั้งหมด**
   - [ ] เปิดข้อสอบนั้นดู ต้องเป็นเวอร์ชันใหม่ และมีบันทึกว่า "Calibrated from n results"
   - [ ] การทดลองของเจ้าหน้าที่ (preview) **ต้องไม่ถูกนับ**

## 6.4 ประเภทข้อสอบ IELTS Reading และข้อความทางกฎหมายใน PDF

1. **ข้อสอบออนไลน์** → IELTS Reading **1 บทอ่าน**
   - [ ] ข้อ 13–14 เป็นแบบ "Choose TWO letters, A–E" เลือกได้ 2 ตัวเท่านั้น และได้ 1 คะแนนต่อตัวที่ถูก
   - [ ] ผลสอบต้องแสดงเป็น /14
2. **คลังข้อสอบ** → แก้บทอ่าน
   - ทดลองเพิ่มกลุ่ม `summary-box` (สรุปความ เลือกคำจากกล่อง) หรือ `note-completion` (มีบรรทัด `~` เป็นข้อความที่มีช่องว่าง)
   - [ ] ถ้าคำสั่งหรือจำนวนตัวเลือกไม่ตรงรูปแบบจริง ระบบต้องแจ้งปัญหา
3. **ชุดข้อสอบ** → สร้างชุด IELTS Reading → **PDF ครู**
   - [ ] หน้า 1 มีกรอบสีส้ม "Disclaimer & rights"
   - [ ] หน้าสุดท้ายมี "Legal notice, licence and disclaimer" ครบ 7–8 หัวข้อ
   - [ ] ท้ายทุกหน้ามีลิขสิทธิ์และลิงก์ตรวจสอบ

## 6.5 ตั้งเวลาให้ AI สร้างข้อสอบเข้าคลัง

1. ผู้ดูแล: **คลังข้อสอบ** → **ตั้งค่าและตารางสร้างข้อสอบ** → เลือกวันและเวลา และจำนวนข้อ SAT ต่อหมวด บทอ่าน IELTS และโจทย์ Writing
2. ส่วนนี้ต้องตั้งค่า AI ก่อน (ข้อ 7) ข้อสอบที่ได้จะเป็น **ฉบับร่าง** เสมอ ครูต้องตรวจคำตอบ ติ๊กยืนยันว่าเป็นต้นฉบับ แล้วจึงอนุมัติ
3. ระบบตรวจรูปแบบให้ตามประเภทข้อสอบ:
   - **SAT:** 4 ตัวเลือก, บทอ่าน 25–150 คำ, คำถามจบด้วย "?", คำอธิบายห้ามอ้างตัวอักษร A–D
   - **IELTS Reading:** คำสั่งต้องระบุจำนวนคำ และต้องตรงกับที่ตั้งไว้
   - **IELTS Writing:** โจทย์ต้องระบุ "Write at least 150/250 words"

## 6.6 สิ่งใหม่ใน v5.7 (ลองตามนี้)

1. **เมนูครบทุกหน้า แต่สิทธิ์ตามระดับผู้ใช้** — เข้าสู่ระบบเป็นนักเรียน (หน้าต่าง Incognito) จะเห็นทุกเมนู
   หน้าที่ใช้ไม่ได้มีรูปกุญแจ กดแล้วจะบอกว่าต้องเป็นระดับใด
   ผู้ดูแลระบบปรับได้ที่ **ตั้งค่า → เมนูและสิทธิ์การใช้งาน** (เอาเครื่องหมายออก = ปิดหน้านั้นสำหรับระดับนั้น
   และเลือกได้ว่าจะแสดงหน้าที่ล็อกหรือซ่อนไปเลย) ระบบให้ "จำกัด" สิทธิ์ได้เท่านั้น ไม่ให้เกินระดับ และผู้ดูแลเปิดได้ทุกหน้าเสมอ
2. **ข่าวสไลด์บนหน้าแรก** — เปิด http://localhost:8000/ จะเห็นการ์ดข่าวเลื่อนเองใต้ส่วนหัว
   กดการ์ดเพื่ออ่านข่าวในหน้าบล็อก หรือกด "ดูข่าวทั้งหมด" ระบบใส่ข่าวตั้งต้นให้ 7 เรื่อง แก้ไข/เก็บ/ลบได้ที่เมนูบล็อกข่าวสาร
3. **ชุดข้อสอบสำเร็จรูป 12 ชุด** — เมนู **ข้อสอบออนไลน์ → ชุดข้อสอบเตรียมสอบเข้าและชุดฝึก**
   - SAT Reading and Writing 3 ชุด (ชุดละ 27 ข้อ 32 นาที)
   - IELTS Academic 3 ชุด (Reading 40 ข้อ 60 นาที + Writing Task 1/2 60 นาที)
   - สวนกุหลาบ ม.1 GATE Program 3 ชุด (คณิต 15 วิทย์ 15 อังกฤษ 5 ไทย 5 · 90 นาที)
   - สวนกุหลาบ ม.1 English Program (EPLUS+) 3 ชุด (อังกฤษ 20 คณิต 10 วิทย์ 10 · 90 นาที)
   ครูเปิดห้องเรียนสดหรือพิมพ์ PDF จากชุดเดียวกันได้ที่เมนู **ชุดข้อสอบ** และเปิด/ปิดให้นักเรียนทำได้
   (รูปแบบ GATE/EP อ้างอิงวิชาที่โรงเรียนประกาศและบทสรุปจากสถาบันกวดวิชา ไม่ใช่ข้อสอบจริง ควรตรวจประกาศโรงเรียนทุกปี)

## 7. ส่วนที่ใช้ AI (ไม่บังคับสำหรับการทดสอบในเครื่อง)

ต้องมีอินเทอร์เน็ตและคีย์ Claude API ห้ามส่งคีย์ในแชตหรือใส่ในหน้าเว็บ

1. ติดตั้ง SDK (ครั้งเดียว): `pip install anthropic`
2. ตั้งคีย์ก่อนเปิดระบบ
   - Windows PowerShell: `$env:ANTHROPIC_API_KEY="..."` แล้ว `python server\app.py --open`
   - macOS/Linux: `export ANTHROPIC_API_KEY=...` แล้ว `./start.sh`
3. หลังบ้าน → **ตั้งค่า AI**: เปิดใช้งาน ใส่รหัสโมเดล ใส่เพดานงบ
4. ทดลองใช้:
   - **บล็อกข่าวสาร** → **ให้ AI เขียน**
   - **คลังข้อสอบ** → **ให้ AI ร่าง**
   - ทำ IELTS Writing แบบฝึก → จะเห็นคำแนะนำจาก AI

ถ้าไม่ตั้งค่า AI ส่วนอื่นทั้งหมดยังทำงานปกติ หน้าตั้งค่า AI จะแสดงว่ายังขาดอะไร

## 8. เมื่อทุกอย่างผ่านแล้ว

1. ส่งออกข้อมูลสำรองจากเครื่อง
2. อัปโหลดโฟลเดอร์ขึ้น PythonAnywhere ตาม `server/DEPLOY.md`
3. นำเข้าข้อมูลสำรองบนเซิร์ฟเวอร์
4. ตั้งค่าบริการตั้งเวลา (cron) ให้เรียก URL ตั้งเวลาทุก 5–15 นาที
