## Learning levels / ระดับการเรียนรู้

### 1. Foundation / พื้นฐาน

- Computational thinking, first programs in Python, electronics with Arduino, and the maths and ethics every AI learner needs.
- ฝึกการคิดเชิงคำนวณ เขียนโปรแกรมแรกด้วย Python เรียนรู้อิเล็กทรอนิกส์กับ Arduino พร้อมคณิตศาสตร์และจริยธรรมที่ผู้เรียน AI ทุกคนต้องมี
- Outcome / ผลลัพธ์: You can write programs, build circuits and explain how AI works. / เขียนโปรแกรม สร้างวงจร และอธิบายได้ว่า AI ทำงานอย่างไร

### 2. Intermediate / ระดับกลาง

- Data structures and algorithms, object-oriented programming in Java and C++, web development, data science, machine learning and native apps with Swift.
- โครงสร้างข้อมูลและอัลกอริทึม การเขียนโปรแกรมเชิงวัตถุด้วย Java และ C++ การพัฒนาเว็บ วิทยาการข้อมูล Machine Learning และแอปเนทีฟด้วย Swift
- Outcome / ผลลัพธ์: You can build complete apps and train your first ML models. / สร้างแอปที่ใช้งานได้ครบถ้วน และฝึกโมเดล Machine Learning ของตัวเองได้

### 3. Advanced / ระดับสูง

- Deep learning, computer vision, large language models, GPU computing with CUDA, and deploying AI at the edge on NVIDIA Jetson.
- Deep Learning, Computer Vision, โมเดลภาษาขนาดใหญ่ (LLM), การประมวลผล GPU ด้วย CUDA และการนำ AI ไปใช้งานจริงบนอุปกรณ์ Edge อย่าง NVIDIA Jetson
- Outcome / ผลลัพธ์: You can design, optimise and deploy real AI systems. / ออกแบบ ปรับแต่ง และนำระบบ AI ไปใช้งานจริงได้

### 4. Research & SI / วิจัยและ SI

- Original research with a mentor: AI agents and reasoning, safety and evaluation, and domain projects that end in a paper, a competition entry or a product.
- ทำวิจัยต้นฉบับร่วมกับอาจารย์ที่ปรึกษา ทั้ง AI Agent และการให้เหตุผล ความปลอดภัยและการประเมินโมเดล ตลอดจนโครงงานเฉพาะสาขา ที่จบด้วยบทความวิจัย ผลงานแข่งขัน หรือผลิตภัณฑ์จริง
- Outcome / ผลลัพธ์: You contribute new knowledge and present it to the world. / สร้างองค์ความรู้ใหม่ และนำเสนอผลงานสู่เวทีโลก

## Research pathway / เส้นทางการทำวิจัย

1. **Ask / ตั้งคำถาม**: Turn curiosity into a clear, testable research question. → _Research question_
2. **Review / ทบทวนวรรณกรรม**: Learn what is already known, find the gap and cite sources properly. → _Annotated bibliography_
3. **Design / ออกแบบและจริยธรรม**: Choose methods, data and evaluation; get ethics approval when people or patient data are involved. → _Research proposal_
4. **Build / สร้างและทดลอง**: Write code, build prototypes and run experiments that others can reproduce. → _Code & prototype_
5. **Analyse / วิเคราะห์ผล**: Use statistics and visualisation to see what the results really say. → _Results & figures_
6. **Write / เขียนรายงาน**: Write in IMRaD structure with clear figures, honest limitations and correct references. → _Manuscript_
7. **Present / นำเสนอ**: Design a poster, give a talk and answer questions from judges and reviewers with confidence. → _Poster & talk_
8. **Publish & compete / ตีพิมพ์และแข่งขัน**: Submit to journals, conferences and competitions, and learn from every round of feedback. → _Paper · award · product_
