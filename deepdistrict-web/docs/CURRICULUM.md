## Learning levels / ระดับการเรียนรู้

- **1. Foundation / พื้นฐาน**: Computational thinking, first programs in Python, electronics with Arduino, and the maths and ethics every AI learner needs.
- **2. Intermediate / ระดับกลาง**: Data structures and algorithms, object-oriented programming in Java and C++, web development, data science, machine learning and native apps with Swift.
- **3. Advanced / ระดับสูง**: Deep learning, computer vision, large language models, GPU computing with CUDA, and deploying AI at the edge on NVIDIA Jetson.
- **4. Research & SI / วิจัยและ SI**: Original research with a mentor: AI agents and reasoning, safety and evaluation, and domain projects that end in a paper, a competition entry or a product.

## Course details / รายละเอียดรายวิชา

### INNO · Personal Innovation Lab: From Topic to Publication
_ห้องแล็บนวัตกรรมเฉพาะบุคคล: จากหัวข้อสู่การตีพิมพ์_

Built entirely around your interests and level. We help you find a topic, then guide you through research, building and writing until you publish or compete.

ออกแบบตามความสนใจและระดับของคุณทั้งหมด เราช่วยหาหัวข้อ แล้วดูแลตลอดการวิจัย การสร้างผลงาน และการเขียน จนถึงการตีพิมพ์หรือการแข่งขัน

- **Prerequisite / พื้นฐาน:** Curiosity. Any level, from age 10. / ความอยากรู้ ทุกระดับ ตั้งแต่อายุ 10 ปี
- **Final project / โปรเจกต์:** Your own topic, chosen with your mentor / หัวข้อของคุณเอง ที่เลือกร่วมกับอาจารย์ที่ปรึกษา
- **Tools:** Personal mentor, Any stack

**Modules / บทเรียน**

1. Interest discovery & topic finding / ค้นหาความสนใจและหัวข้อ
2. Feasibility & literature scan / ประเมินความเป็นไปได้และสำรวจวรรณกรรม
3. Personal plan & milestones / แผนเฉพาะบุคคลและหลักไมล์
4. Build, experiment, iterate / สร้าง ทดลอง และปรับปรุง
5. Write, present, polish / เขียน นำเสนอ และขัดเกลา
6. Publish or compete / ตีพิมพ์หรือแข่งขัน

**Outcomes / ผลลัพธ์**

- Your own innovation in an area you care about / นวัตกรรมของคุณเองในเรื่องที่คุณสนใจ
- A paper, competition entry or product / บทความ ผลงานแข่งขัน หรือผลิตภัณฑ์
- A portfolio that stands out / พอร์ตโฟลิโอที่โดดเด่น

### CT100 · Computational Thinking & Problem Solving
_การคิดเชิงคำนวณและการแก้ปัญหา_

Decomposition, patterns, abstraction and algorithms, from unplugged activities to block coding.

การแยกย่อยปัญหา การหารูปแบบ การคิดเชิงนามธรรม และการออกแบบอัลกอริทึม ตั้งแต่กิจกรรมไม่ใช้คอมพิวเตอร์จนถึงการเขียนโค้ดแบบบล็อก

- **Prerequisite / พื้นฐาน:** None, ages 8+ / ไม่ต้องมีพื้นฐาน อายุ 8 ปีขึ้นไป
- **Final project / โปรเจกต์:** An interactive game or animated story / เกมหรือแอนิเมชันเล่าเรื่องแบบโต้ตอบ
- **Tools:** Scratch, Flowcharts

**Modules / บทเรียน**

1. Unplugged algorithms / อัลกอริทึมแบบไม่ใช้คอมพิวเตอร์
2. Patterns & abstraction / การหารูปแบบและการคิดเชิงนามธรรม
3. Flowcharts & pseudocode / ผังงานและรหัสเทียม
4. Block coding with Scratch / เขียนโค้ดแบบบล็อกด้วย Scratch
5. Debugging mindset / วิธีคิดในการหาข้อผิดพลาด
6. Showcase: interactive story or game / ผลงาน: เรื่องเล่าหรือเกมแบบโต้ตอบ

**Outcomes / ผลลัพธ์**

- Describe a problem as clear steps / อธิบายปัญหาเป็นขั้นตอนที่ชัดเจน
- Build programs with loops and conditions / สร้างโปรแกรมที่มีการวนซ้ำและเงื่อนไข
- Find and fix mistakes systematically / หาและแก้ข้อผิดพลาดได้อย่างเป็นระบบ

- Use AI tools responsibly for study / ใช้เครื่องมือ AI ในการเรียนอย่างรับผิดชอบ

## Research pathway / เส้นทางการทำวิจัย

1. **Ask / ตั้งคำถาม**: Turn curiosity into a clear, testable research question.
2. **Review / ทบทวนวรรณกรรม**: Learn what is already known, find the gap and cite sources properly.
3. **Design / ออกแบบและจริยธรรม**: Choose methods, data and evaluation; get ethics approval when people or patient data are involved.
4. **Build / สร้างและทดลอง**: Write code, build prototypes and run experiments that others can reproduce.
5. **Analyse / วิเคราะห์ผล**: Use statistics and visualisation to see what the results really say.
6. **Write / เขียนรายงาน**: Write in IMRaD structure with clear figures, honest limitations and correct references.
7. **Present / นำเสนอ**: Design a poster, give a talk and answer questions from judges and reviewers with confidence.
8. **Publish & compete / ตีพิมพ์และแข่งขัน**: Submit to journals, conferences and competitions, and learn from every round of feedback.
