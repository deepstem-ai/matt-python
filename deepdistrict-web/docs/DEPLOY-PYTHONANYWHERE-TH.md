# วิธีเอาเว็บ DeepDistrict ขึ้นออนไลน์ด้วย PythonAnywhere (ฉบับง่าย ไม่ต้องมีพื้นฐาน)

ใช้เวลาประมาณ 20–30 นาที · ทำครั้งเดียว · เริ่มต้นฟรี

สิ่งที่ต้องมี
- ไฟล์ zip ล่าสุด เช่น `deepdistrict-web-v6.5r4.zip` (ไม่ต้องแตกไฟล์บนเครื่อง)
- อีเมล 1 อัน
- คอมพิวเตอร์ (ทำบนมือถือไม่สะดวก)

> คำว่า **ชื่อผู้ใช้** ในคู่มือนี้ หมายถึงชื่อบัญชี PythonAnywhere ที่คุณตั้งในขั้นที่ 1
> เช่น ตั้งชื่อว่า `deepdistrict` เว็บจะอยู่ที่ `https://deepdistrict.pythonanywhere.com`

---

## ขั้นที่ 1 · สมัครบัญชี (5 นาที)

1. เปิด **https://www.pythonanywhere.com**
2. กดปุ่ม **Pricing & signup** (มุมขวาบน)
3. ในกล่อง **Beginner** (ฟรี) กด **Create a Beginner account**
4. กรอก
   - **Username** = ชื่อผู้ใช้ (ภาษาอังกฤษตัวเล็ก ไม่มีเว้นวรรค จะกลายเป็นชื่อเว็บ เช่น `deepdistrict`)
   - **Email** และ **Password**
5. ติ๊กยอมรับเงื่อนไข → กด **Register**
6. เปิดอีเมล กดลิงก์ยืนยัน (Confirm)

✅ เสร็จแล้วจะเห็นหน้า **Dashboard** มีแถบเมนูด้านบน: Dashboard · Consoles · Files · Web · Tasks · Databases

---

## ขั้นที่ 2 · อัปโหลดไฟล์ zip (3 นาที)

1. กดแถบ **Files** ด้านบน
2. กดปุ่มสีเหลือง **Upload a file**
3. เลือกไฟล์ `deepdistrict-web-v6.5r4.zip` จากเครื่อง → รอจนขึ้นชื่อไฟล์ในรายการ

---

## ขั้นที่ 3 · แตกไฟล์ zip (2 นาที)

1. กดแถบ **Consoles** ด้านบน
2. ใต้หัวข้อ **Start a new console** กด **Bash**
3. จะเห็นหน้าจอสีดำ (ไม่ต้องตกใจ แค่พิมพ์ตามนี้)
4. พิมพ์คำสั่งนี้ (หรือคัดลอกไปวาง) แล้วกด **Enter**

   ```
   unzip deepdistrict-web-v6.5r4.zip
   ```

5. จะมีตัวหนังสือไหลขึ้นมาเยอะ ๆ รอจนหยุด
6. ตรวจสอบ: พิมพ์คำสั่งนี้ แล้วกด **Enter**

   ```
   ls deepdistrict-web
   ```

   ✅ ต้องเห็นคำว่า `admin  assets  index.html  pages  server …`

7. ปิดแท็บหน้าจอสีดำได้เลย (กดโลโก้ PythonAnywhere มุมซ้ายบนเพื่อกลับ Dashboard)

---

## ขั้นที่ 4 · สร้างเว็บ (5 นาที)

1. กดแถบ **Web** ด้านบน
2. กดปุ่ม **Add a new web app** → กด **Next**
3. หน้าที่ให้เลือก framework: เลือก **Manual configuration (including virtualenvs)**
   ⚠️ อย่าเลือก Django หรือ Flask
4. เลือก Python เวอร์ชัน **ตัวเลขสูงสุด** ในรายการ (เช่น Python 3.13) → กด **Next** → **Next**
5. ✅ จะเห็นหน้าตั้งค่าเว็บ ด้านบนมีชื่อเว็บ `ชื่อผู้ใช้.pythonanywhere.com`

---

## ขั้นที่ 5 · บอกเว็บว่าโปรแกรมอยู่ที่ไหน (5 นาที) — ขั้นสำคัญที่สุด

1. ในหน้า **Web** เลื่อนลงมาที่หัวข้อ **Code**
2. ตรง **WSGI configuration file:** กดลิงก์สีฟ้า (ชื่อประมาณ `/var/www/ชื่อผู้ใช้_pythonanywhere_com_wsgi.py`)
3. จะเปิดหน้าแก้ไขไฟล์ ที่มีข้อความภาษาอังกฤษยาว ๆ
4. **ลบข้อความเดิมทั้งหมด**: คลิกในกล่อง → กด `Ctrl + A` (Mac: `Cmd + A`) → กด `Delete`
5. วาง 3 บรรทัดนี้ แล้ว **เปลี่ยนคำว่า ชื่อผู้ใช้ เป็นชื่อบัญชีของคุณ**

   ```python
   import sys
   sys.path.insert(0, "/home/ชื่อผู้ใช้/deepdistrict-web/server")
   from wsgi import application
   ```

   ตัวอย่าง ถ้าชื่อผู้ใช้คือ `deepdistrict` บรรทัดที่ 2 ต้องเป็น
   `sys.path.insert(0, "/home/deepdistrict/deepdistrict-web/server")`

6. กดปุ่ม **Save** (มุมขวาบน สีเขียว)
7. กดแถบ **Web** เพื่อกลับ

---

## ขั้นที่ 6 · เปิด HTTPS และเปิดเว็บ (2 นาที)

1. ในหน้า **Web** เลื่อนลงไปหัวข้อ **Security** → เปิด **Force HTTPS** ให้เป็น **Enabled**
2. เลื่อนกลับขึ้นด้านบน กดปุ่มสีเขียวใหญ่ **Reload ชื่อผู้ใช้.pythonanywhere.com**
3. รอ 10–20 วินาที แล้วเปิดเว็บ:
   - เว็บไซต์: `https://ชื่อผู้ใช้.pythonanywhere.com`
   - ระบบหลังบ้าน: `https://ชื่อผู้ใช้.pythonanywhere.com/admin/`

✅ ถ้าเห็นหน้าเว็บ DeepDistrict = ขึ้นออนไลน์สำเร็จ 🎉

❌ ถ้าเห็นหน้า "Something went wrong" → ดูหัวข้อ **ถ้ามีปัญหา** ด้านล่าง

---

## ขั้นที่ 7 · สร้างบัญชีแอดมิน (2 นาที)

1. เปิด `https://ชื่อผู้ใช้.pythonanywhere.com/admin/`
2. ครั้งแรกจะขึ้นหน้าให้สร้างบัญชีผู้ดูแลระบบ → ใส่ชื่อ อีเมล และรหัสผ่าน **ที่ยากเดา** (อย่างน้อย 12 ตัว มีตัวเลขและตัวอักษร)
3. เข้าสู่ระบบ

---

## ขั้นที่ 8 · เอาข้อมูลนักเรียนขึ้นเว็บ (เลือกทางเดียว)

**ทาง ก — ถ้าเคยใช้ระบบในเครื่องตัวเองและแก้ข้อมูลไว้แล้ว (แนะนำ)**
1. บน **เครื่องตัวเอง**: เปิดระบบหลังบ้าน → **ตั้งค่า** → หัวข้อ **สำรองและจัดการข้อมูล** → กด **ส่งออกไฟล์สำรอง (.json)** → ได้ไฟล์ `deepdistrict-backup-….json`
2. บน **เว็บออนไลน์**: ระบบหลังบ้าน → **ตั้งค่า** → **สำรองและจัดการข้อมูล** → กด **นำเข้าไฟล์สำรอง…** → เลือกไฟล์จากข้อ 1
3. ขึ้นถามว่า "แทนที่ข้อมูลปัจจุบันทั้งหมดด้วยไฟล์สำรองนี้?" → กด **OK**
4. ขึ้น "กู้คืนข้อมูลแล้ว" = สำเร็จ · จากนี้ให้เข้าสู่ระบบด้วย **อีเมลและรหัสผ่านเดิมจากเครื่องตัวเอง**
   (บัญชีแอดมินที่เพิ่งสร้างในขั้นที่ 7 จะถูกแทนที่ด้วยบัญชีจากไฟล์สำรอง)

**ทาง ข — ไม่ต้องทำอะไร**
ระบบใส่ข้อมูลนักเรียนจริง 6 คน คาบเรียน 62 คาบ และยอดชำระให้เองตั้งแต่เปิดครั้งแรก
(แต่สิ่งที่เคยแก้ในเครื่องตัวเอง เช่นการต่อคอร์ส จะไม่มา)

## ขั้นที่ 9 · ตั้งเวลาให้ระบบทำงานเองทุก 15 นาที (5 นาที)

ใช้สำหรับ: บันทึกคาบที่ผ่านไปแล้วให้อัตโนมัติ ส่งการแจ้งเตือน และดึงข่าว

1. ระบบหลังบ้าน → **การแจ้งเตือน** (รูปกระดิ่ง) → แท็บของแอดมิน → หา **ตัวตั้งเวลาเมื่อขึ้นโฮสต์** → คัดลอกลิงก์ทั้งบรรทัด
   ⚠️ ลิงก์นี้เป็นความลับ อย่าส่งให้คนอื่น
2. เปิด **https://cron-job.org** → **Sign up** (ฟรี) → ยืนยันอีเมล
3. กด **Create cronjob**
   - **Title**: `DeepDistrict`
   - **URL**: วางลิงก์จากข้อ 1
   - **Execution schedule**: เลือก **Every 15 minutes**
4. กด **Create**

## 🔄 อัปเดตเป็นเวอร์ชันใหม่ (ครั้งต่อไป)

1. แถบ **Files** → **Upload a file** → เลือก zip เวอร์ชันใหม่ เช่น `deepdistrict-web-v6.6r1.zip`
2. แถบ **Consoles** → **Bash** → พิมพ์ (ใส่ชื่อไฟล์ใหม่) แล้วกด Enter

   ```
   unzip -o deepdistrict-web-v6.6r1.zip
   ```

   (`-o` = เขียนทับไฟล์เดิม · ข้อมูลนักเรียนอยู่ใน `server/data` ซึ่งไม่ถูกเขียนทับ)
3. แถบ **Web** → กดปุ่มสีเขียว **Reload**
4. เปิดเว็บ แล้วกด `Ctrl + Shift + R` (Mac: `Cmd + Shift + R`) เพื่อโหลดหน้าใหม่

## ❓ ถ้ามีปัญหา

| อาการ | วิธีแก้ |
|---|---|
| หน้า "Something went wrong" | แถบ **Web** → หัวข้อ **Log files** → กด **Error log** → คัดลอกบรรทัดล่าง ๆ ส่งมาให้ช่วยดู · มักเกิดจากพิมพ์ **ชื่อผู้ใช้** ในขั้นที่ 5 ผิด |
| `No module named wsgi` | ชื่อโฟลเดอร์ในขั้นที่ 5 ผิด ตรวจว่าเป็น `/home/ชื่อผู้ใช้/deepdistrict-web/server` |
| `unzip: cannot find` | ชื่อไฟล์ zip พิมพ์ไม่ตรง → พิมพ์ `ls` แล้ว Enter เพื่อดูชื่อไฟล์จริง |
| เว็บยังเป็นเวอร์ชันเก่า | ลืมกด **Reload** ในแถบ Web หรือกด `Ctrl + Shift + R` ในเบราว์เซอร์ |
| ลืมรหัสผ่านแอดมิน | ส่งข้อความมาให้ช่วย (แก้ได้จาก Bash โดยไม่ต้องลบข้อมูล) |
