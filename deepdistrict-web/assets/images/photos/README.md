# Photos

The site currently uses original illustrations generated by `tools/generate_images.py`
(no third-party copyright). To use real photography:

1. Use your own photos (with written consent from anyone shown, and a guardian's consent
   for minors, under the PDPA), or images under a licence that allows commercial use
   (for example the Unsplash or Pexels licences, or CC0). Keep a record of the source.
2. Export as `.webp` or `.jpg`, about 1920 px wide for heroes and 1200 px for sections,
   under ~300 KB each.
3. Save them here and point the `<img src>` in the page at the new file, or replace an
   existing illustration while keeping its file name.
4. Write a meaningful `alt` text in both languages where the image carries meaning.

Avoid images showing product logos or school uniforms unless you have permission.
