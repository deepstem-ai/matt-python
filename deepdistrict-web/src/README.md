# src/ — reserved for the next phase

Empty on purpose. When the site moves to a build step (see `docs/ROADMAP.md`),
source files go here:

- `src/components/` — header, footer, panel, card, manifest row, form field
- `src/content/` — page copy and data as Markdown/JSON (replaces `assets/data/content.js`)

Until then, the site is plain HTML in the project root and `pages/`.
